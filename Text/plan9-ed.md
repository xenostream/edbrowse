Plan 9 ED text Editor
---

### 이름

`ed` - 텍스트 편집기

### 구문

```
ed [ - ] [ -o ] [ file ]
```


### 설명

`ed` 는 표준 텍스트 편집기(*standard text editor*)입니다.

*file* 인수가 지정되면 ed는 해당 파일에 대해 `e` 명령어(아래 참조)를 시뮬레이션합니다. 즉, 파일을 ed의 버퍼로 읽어와 편집할 수 있게 합니다.  

옵션은 다음과 같습니다.

- `-` :: `e`, `r` 및 `w` 명령에 의한 문자(byte) 수 표시와 `!` 명령에 의한 확인용 `!` 표시를 억제합니다.

- `-o` :: (출력 파이프용) `w` 명령에 의한 쓰기를 제외하고 모든 출력을 표준 오류 파일에 기록합니다. 파일이 지정되지 않은 경우 `/fd/1` 을 기억된 파일로 설정합니다. 아래 `e` 명령을 참조합니다.

Ed는 현재 편집 중인 파일의 복사본인 `버퍼` (*buffer*)에서 작동합니다. 버퍼의 변경 사항은 `w` (쓰기) 명령을 실행할 때까지 파일에 반영되지 않습니다. 즉, 현재 편집 중인 텍스트의 복사본은 버퍼라는 임시 공간에 저장됩니다.

ed 명령어는 간단하고 규칙적인 구조를 가집니다: 0개, 1개 또는 2개의 주소에 이어 단일 문자 명령어가 오며 그 뒤에 명령어의 매개변수가 올 수 있습니다. 주소(들)은 버퍼의 하나 이상의 줄을 지정합니다. 주소가 누락된 경우 기본 주소(현재 라인 즉, 닷)로 채워집니다.

일반적으로 한 줄에 하나의 명령어만 사용합니다. 특정 명령어는 버퍼에 텍스트를 추가할 수 있습니다. ed가 텍스트를 받아들일 동안은 "입력 모드에 있다!" 고 표현합니다. 이 모드에선 명령어가 인식되지 않으며 모든 입력은 단순히 (버퍼에) 수집될 뿐입니다. 줄 맨 앞에 마침표 `.` 를 단독 입력하면 입력 모드에서 나옵니다.

ed는 `regexp(6)` 에 설명된 정규 표현식을 지원합니다. 정규 표현식은 주소에서 줄을 지정하는 용도로 사용되며 특정 명령어(아래의 `s` 명령어 참조)에선 변경할 줄의 일부를 지정할 때도 사용됩니다. 정규 표현식 메타(특수)문자를 일반 문자로 사용할 경우 해당 문자 앞에 `\` 를 붙입니다. 이는 정규 표현식을 둘러싸는 문자(대개 `/`)와 `\` 에도 적용됩니다.

ed의 주소 지정을 이해하려면 "‘현재 줄’ (*current line*)이 존재한다!" 는 점을 알아야 합니다. 일반적으로 현재 줄은 명령어의 영향을 가장 최근에 받은 줄이지만 현재 줄에 미치는 정확한 영향은 각 명령어 설명에서 다룹니다. 

주소는 다음과 같이 구성됩니다.

1. `.` 문자(통상 ‘닷’ 또는 "dot")는 현재 줄을 가리킵니다.

2. `$` 문자는 버퍼의 마지막 줄을 지정합니다.

3. 십진수 n 은 버퍼의 n 번째 줄을 지정합니다.

4. `'x` 는 이름 x 로 표시(*mark*)된 줄을 지칭하며 x 는 소문자여야 합니다. 줄은 `k` 명령어로 표시(*mark*)합니다.

5. 슬래시(`/`) 로 묶인 정규 표현식은 현재 줄에서 앞으로 검색해서 정규 표현식과 일치하는 문자열이 포함된 첫 번째 줄에서 멈추는 방식으로 해당 줄을 지정(선택)합니다. 필요할 경우 검색은 버퍼 시작 부분으로 되돌아갑니다.(*wrap around*)

6. 물음표 `?` 로 둘러싸인 정규 표현식은 현재 줄에서 뒤로 검색해서 정규 표현식과 일치하는 문자열이 포함된 첫 번째 줄에서 멈추는 방식으로 해당 줄을 지정합니다. 필요할 경우 검색은 버퍼 끝으로 되돌아갑니다.

7. 주소 뒤에 더하기 기호 `+` 또는 빼기 기호 `-` 와 10진수가 따라오면 해당 주소에서 지정한 줄 수만큼 더한(또는 뺀) 위치를 지정합니다. 이때 더하기 기호를 생략할 수 있습니다.

8. 주소 뒤에 `+` (또는 `-`)와 슬래시로 묶인 정규 표현식이 따라오면 해당 주소의 바로 뒤(또는 앞)에 일치하는 첫 번째 줄을 지정합니다. 필요할 경우 검색은 버퍼 끝에서 다시 시작됩니다. `+` 는 생략할 수 있으므로 `0/x/` 는 버퍼에서 `x` 가 포함된 첫 번째 줄을 가리킵니다. 정규 표현식을 `?` 로 묶으면 검색 방향이 반대로 바뀝니다.
         
9. 주소가 `+` 또는 `-` 로 시작할 경우 현재 줄 기준으로 더하기 또는 뺄셈이 적용됩니다. 예를 들어, `-5` 는 `.-5` 를 의미하는 것으로 해석됩니다.

10. 주소가 `+` 또는 `-` 로 끝날 경우 1 을 더하거나 뺍니다. 이 규칙과 규칙 9의 결과로 인해 주소 `-` 는 현재 줄 바로 앞 줄을 가리킵니다.  또한, 끝에 오는 `+` 및 `-` 문자는 누적 효과가 있으므로 `--` 는 현재 줄에서 2를 뺀 줄을 가리킵니다.

11. 이전 버전의 편집기와의 호환성을 위해 `^` 문자는 `-` 와 동일하게 취급됩니다.

명령어는 주소를 0개, 1개 또는 2개 요구할 수 있습니다. 주소를 요구하지 않는 명령어에 주소를 지정한 경우는 오류로 간주합니다. 주소를 1개 또는 2개 허용하는 명령어에 주소가 부족할 경우 기본 주소를 가정합니다. 만약 명령어가 요구하는 것보다 많은 주소를 지정하면 마지막 1개 또는 2개(허용되는 개수에 따라 다름)가 사용됩니다.

주소는 일반적으로 쉼표 `,` 로 구분됩니다. 세미콜론 `;` 으로 구분할 수도 있습니다. 이 경우 다음 주소를 해석하기 전에 현재 줄이 이전 주소로 설정됩니다. 쉼표나 세미콜론 앞에 주소가 없으면 1 번 줄로 간주되며 뒤에 주소가 없으면 버퍼 마지막 줄로 간주됩니다. 두 개의 주소가 연속될 경우 두 번째 주소는 첫 번째 주소 다음 줄과 일치해야 합니다.

다음 ed 명령어 목록에서 기본 주소는 괄호 안에 표시합니다. 따라서 괄호는 주소의 일부가 아니며 주소가 "기본값" 임을 나타내기 위해서만 사용됩니다. `점` (`.`)은 "현재 줄" 을 의미합니다.

| 명령 | 설명 |
| :--- | :--- |
`(.)a`<br>`<text>`<br>`.` | *append* : 텍스트를 지정한 줄 뒤에 추가합니다. 마지막으로 입력한 줄에 점(*dot*)이 남습니다. 이 명령은 주소 `0` 을 사용할 수 있으며 텍스트는 버퍼 맨 앞에 배치됩니다. 
`(.,.)b[+-][pagesize][pln]` | *browse*: 기본 20줄로 구성된 `페이지` 를 출력합니다. 선택 사항인 `+` (기본값) 또는 `-` 는 다음 페이지 또는 이전 페이지를 출력할지 여부를 지정합니다. 선택 사항인 *pagesize* 는 한 페이지에 포함될 줄 수입니다. 선택 사항인 `p`, `n` 또는 `l` 을 지정하면 지정한 형식(기본값은 `p`)으로 출력합니다. 페이지 크기와 형식은 `b` 명령어에 기억됩니다. 점(`.`)은 마지막으로 표시된 줄에 남습니다.
`(.,.)c`<br>`<text>`<br>`.` | *change*: 지정한 줄을 삭제한 다음 이 줄(들)을 대체할 입력 텍스트를 받아들입니다. 커서(`.`)는 마지막으로 입력한 줄에 남습니다. 입력한 줄이 없는 경우 커서는 삭제한 줄 바로 앞 줄에 남습니다.
`(.,.)d` | 버퍼에서 지정한 줄을 삭제합니다. 커서는 마지막으로 삭제한 줄 다음 줄로 이동하거나 삭제한 줄 뒤에 이어지는 줄이 없을 경우 버퍼 마지막 줄로 이동합니다.
`e 파일명` | *edit* : 버퍼 전체 내용을 삭제한 다음 지정한 파일을 버퍼로 읽어들입니다. 커서는 버퍼 마지막 줄로 이동합니다. 읽은 문자 수를 표시합니다. 파일명은 나중에 `e`, `r` 또는 `w` 명령을 사용할 때를 대비해서 기억됩니다. 파일명이 지정되지 않은 경우 기억한 이름을 사용합니다.
`E 파일명` | *forced edit* : 아래 `q` 명령을 참조합니다.
`f 파일명` | *filename* : 현재 기억된 파일 이름을 출력합니다. 파일명이 지정된 경우 현재 기억된 파일 이름을 파일명으로 변경합니다.
`(1,$)g/정규 표현식/명령어 목록`<br>`(1,$)g/정규 표현식/`<br>`(1,$)g/정규 표현식` | *global* : 주어진 정규 표현식과 일치하는 모든 줄을 출력합니다. 일치하는 줄에 커서를 위치시킨 상태에서 명령어 목록을 실행합니다. 단일 명령어나 여러 명령어 중 첫 번째 명령어는 전역 명령어와 같은 줄에 표시합니다. 여러 줄로 구성된 명령 목록의 마지막 줄을 제외한 모든 줄은 `\` (줄바꿈, 개행문자)문자로 끝나야 합니다. `a`, `i`, `c` 명령어의 입력 모드를 종료하는 `.` 은 명령어 목록 마지막 줄에 위치할 경우 생략할 수 있습니다. 명령어 목록엔 `g` 및 `v` 명령을 사용할 수 없습니다. 정규 표현식을 구분하는 `/` 구분자 대신 공백이나 줄바꿈 이외의 모든 문자를 사용할 수 있습니다. 두 번째와 세 번째 형식은 `g/정규 표현식/p` 를 의미합니다.
`(.)i`<br>`<text>`<br>`.` | *insert* : 텍스트를 대상 줄 앞에 삽입합니다. 점(커서)은 마지막으로 입력한 줄에 남거나 입력한 줄이 없는 경우 앞 줄에 남습니다. 이 명령은 텍스트 배치 위치만 `a` 명령과 다릅니다.
`(.,.+1)j` | *join* : 지정한 줄(들)을 하나의 줄로 병합합니다. 중간의 줄바꿈 문자는 삭제됩니다. 결과 줄에 점(.)이 남습니다.
`(.)kx` | *bookmark* : 지정한 줄에 x 라는 이름을 지정합니다. x 는 반드시 소문자여야 합니다. 이후 `'x` 형식은 이 줄을 가리킵니다.
`(.,.)l` | *list* : 지정한 줄을 모호함이 없이 명확히 출력합니다: 탭은 `\t`, 백스페이스는 `\b`, 백슬래시는 `\`, 비출력 문자는 백슬래시 `\`, `x` 그리고 4자리 16진수 숫자로 출력합니다. 긴 줄은 접혀서 표시되며 두 번째 및 그 이후 하위 줄은 탭 한 칸만큼 들여쓰기됩니다. 줄 마지막 문자가 공백일 경우 `\n` 이 붙습니다. `l` 은 `p` 명령어와 마찬가지로 I/O 명령어가 아닌 모든 명령어 뒤에 추가할 수 있습니다.
`(.,.)ma` | *move* : a 로 지정한 줄 뒤에 지정한 줄(들)을 재배치(이동)합니다. 이동한 마지막 줄에 점(.)이 남습니다.
`(.,.)n` | *number* : `p` 명령을 수행하되 줄 앞에 줄 번호와 탭간격을 붙입니다. `p` 명령어와 마찬가지로 `n` 은 I/O 명령이 아닌 모든 명령 뒤에 추가할 수 있습니다.        
`(.,.)p` | *print* : 지정한 줄을 출력합니다. 출력한 마지막 줄에 점(`.`)이 남습니다. I/O 명령어가 아닌 명령어 뒤에 `p` 를 추가하면 명령어 실행 후 현재 줄이 출력됩니다.
`(.,.)P` | *print* : `p` 명령어와 동의어입니다.
`q` | *quit* : 편집기를 종료합니다. 파일 자동 저장은 수행되지 않습니다. 마지막 `w`, `q` 또는 `e` 명령 이후 버퍼가 수정된 경우 `q` 또는 `e` 명령은 오류로 간주됩니다.
`Q` | *forced quit* : 무조건 종료합니다.
`($)r 파일명` | *read* : 지정한 파일을 지정한 줄 이후에 읽어옵니다. 파일명이 지정되지 않은 경우 저장된 파일명을 사용합니다. 저장된 파일명이 없는 경우 파일명이 저장됩니다. 읽기가 성공하면 읽은 문자 수를 출력합니다. 파일에서 읽은 마지막 줄에 점(`.`)이 남습니다.
`(.,.)sn/정규식/대체문자열/`<br>`(.,.)sn/정규식/대체문자열/g`<br>`(.,.)sn/정규식/치환` | *substitute* : 지정한 줄에서 지정한 정규식이 나타나는 위치를 검색합니다. n 개의 일치 항목이 발견된 줄(n 을 지정하지 않으면 기본값은 1 입니다)에서 n 번째로 일치하는 문자열을 지정한 치환 문자열로 대체합니다. 명령어 뒤에 전역 치환 지시자 `g` 가 나타나면 해당 줄의 모든 일치 항목을 치환합니다. 지정한 모든 줄에서 치환이 실패하면 오류가 발생합니다. 공백이나 줄바꿈 이외의 모든 문자를 `/` 구분자 대신 사용해서 정규 표현식과 치환 문자열을 구분할 수 있습니다. 점(`.`)은 대체가 완료된 마지막 줄에 남습니다. 세 번째 형식은 `sn/정규 표현식/대체 문자열/p` 를 의미합니다. 두 번째 `/` 는 대체 문자열이 비어 있을 경우 생략할 수 있습니다.<br><br>대체 문자열에 앰퍼샌드 `&` 가 나타나면 정규 표현식과 일치하는 문자열로 대체됩니다. n 이 숫자인 `\n` 은 `(` 와 `)` 로 묶인 n 번째 부분 표현식과 일치하는 텍스트로 대체(역참조)됩니다. 중첩 괄호로 묶인 부분 표현식이 있을 경우 n 은 왼쪽부터 `(` 의 출현 횟수를 세어 결정됩니다.<br><br>리터럴 `&`, `/`, `\` 또는 줄바꿈 문자는 앞에 `\` 를 붙여 치환 대상에 리터럴 문자로 포함할 수 있습니다.
`(.,.)ta` | *transfer* : a 로 지정한 줄 뒤에 지정한 줄(들)을 복사합니다. 복사본의 마지막 줄에 점(.)이 남습니다.
`(.,.)u` | *undo* : 첫 번째 지정한 첫 번째 줄(sic)의 이전 내용을 복원합니다. 이 줄은 치환이 수행된 마지막 줄이어야 합니다(double sic).
`(1,$)v/정규 표현식/명령 목록` | *reverse* : 전역 명령 `g` 와 동일하지만 정규 표현식과 일치하는 줄을 제외한 모든 줄에 점(`.`)이 초기값으로 설정된 상태에서 명령 목록이 실행된다는 점만 다릅니다.
`(1,$)w 파일명` | *write* : 지정한 줄(들)을 주어진 파일에 기록합니다. 파일이 존재하지 않으면 모드 666(누구나 읽기 및 쓰기 가능)으로 새로 생성합니다. 파일명이 지정되지 않으면 저장된 파일명이 있을 경우 이를 사용합니다. 저장한 파일명이 없으면 파일명이 저장됩니다. 점(`.`)은 변함없습니다. 쓰기가 성공하면 쓰여진 문자 수를 출력합니다.         
`(1,$)W 파일명` | *append write* : `w` 명령을 실행하되 기존 파일 내용을 덮어쓰지 않고 끝에 추가합니다.
`($)=` | *print line number* : 지정한 줄의 줄 번호를 출력합니다. 점(.)은 변경되지 않습니다.
`!셸 명령` | *execute shell command* : `!` 뒤의 쉘 명령을 rc(1) 쉘로 전송해서 명령으로 해석합니다. 점(.)은 변경되지 않습니다.
`(.+1), <줄바꿈>` | 명령어가 없는 주소는 `p` 명령어로 간주합니다. 주소에서 종결 기호 `/` 를 생략할 수 있습니다. 빈 줄만 있는 경우 `.+1p` 와 동일하며 텍스트를 한 줄씩 순차적으로 이동할 때 유용합니다.

중단 신호(`DEL`)가 전송되면 ed는 `?` 를 출력하고 명령 모드로 돌아갑니다.

파일을 읽을 때 ed는 `NUL` 문자와 마지막 줄바꿈 이후의 모든 문자를 제거합니다.
