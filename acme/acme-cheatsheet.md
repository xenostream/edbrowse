# Acme Cheat sheet

## Mouse buttons

* **버튼 1** — 텍스트를 선택합니다. 더블 클릭하면 일반적인 확장 동작이 적용됩니다. 
* **버튼 2** — 텍스트를 명령어로 실행합니다. 빈 문자열을 클릭하면 Acme가 클릭 지점 주변을 확장해서 명령어를 찾습니다. 
* **버튼 3** — 파일을 열거나, 주소를 따라가거나, 리터럴 텍스트를 검색합니다. 


## The standard built-in commands

다음은 관례상 첫 글자를 대문자로 표기하며, **버튼 2** 를 눌러 실행하는 Acme에 내장된 명령어입니다. 


### Editing and clipboard

* **Cut** — 가장 최근에 선택한 텍스트를 삭제하고 스나프 버퍼에 저장합니다.  
* **Paste** — 가장 최근에 선택한 텍스트를 스나프 버퍼의 내용으로 대체합니다. 
* **Snarf** — 선택한 텍스트를 삭제하지 않고 스나프 버퍼에 복사합니다. 
* **Undo** — 마지막으로 수행한 텍스트 변경 사항 또는 일련의 변경 사항을 되돌립니다. 
* **Redo** — `Undo` 로 취소된 작업을 다시 실행합니다. 

### Window and column management

* **Del** — 현재 창을 삭제합니다. 단, 변경된 내용이 있는 경우 Acme가 경고 메시지를 표시하며, 두 번째 `Del` 명령을 입력해야 삭제가 완료됩니다. 
* **Delete** — 변경 여부 확인 없이 현재 창을 강제로 삭제합니다. 
* **Delcol** — 현재 열과 그 열에 속한 모든 창이 변경되지 않았는지 확인한 후 삭제합니다.  
* **New** — 새 창을 만듭니다. 파일 인수가 주어지면 해당 파일을 창으로 불러옵니다.  
* **Newcol** — 새 열을 만듭니다.  
* **Zerox** — 가장 최근에 선택된 텍스트가 포함된 창의 복사본을 만듭니다.  
* **Sort** — 열 내의 창 이름을 사전순으로 정렬합니다.  

### File I/O and session state

* **Get** — 변경 여부 확인 후, 파일을 창으로 불러와서 기존 내용을 덮어씁니다. 인수를 지정하면 해당 파일을 불러오되 창 이름을 변경하지 않습니다.  
* **Put** — 창 내용을 해당 파일에 기록합니다. 인수를 지정하면 지정된 파일에 기록합니다.  
* **Putall** — 이름이 기존 일반 파일을 가리키는 모든 변경된 창을 파일에 기록합니다.  
* **Dump** — Acme의 상태를 저장합니다. 기본 저장 위치는 `$HOME/acme.dump` 입니다.  
* **Load** — 덤프 파일(기본값: `$HOME/acme.dump`)에서 Acme 상태를 복원합니다.  
* **Exit** — 창이 더티 상태가 아닌지 확인한 후 Acme를 종료합니다.  

### Searching and addressing

* **Look** — 인수를 사용하거나, 인수가 지정되지 않은 경우 본문에서 선택된 텍스트를 사용해서 **문자 그대로의** 텍스트가 나타나는 위치를 검색합니다.   
* **Edit** — 현재 창 본문에 **sam 편집 명령** 을 실행합니다. Acme는 `k`, `n`, `q` 및 `!` 명령을 제외한 sam 언어를 구현하며, `=` 는 약간 다릅니다. 

### Environment and formatting

* **Font** — 인수를 지정하지 않으면 고정폭 글꼴과 비례폭 글꼴을 전환하거나, 지정된 파일의 글꼴을 설정합니다. 글꼴 이름 앞에 `var` 또는 `fix`를 붙이면 이후 열릴 창의 기본값도 변경됩니다.  
* **Tab** — 현재 창의 탭 너비를 설정합니다. 인수를 지정하지 않으면 현재 설정 값을 표시합니다.  
* **Indent** — 자동 들여쓰기 모드를 설정합니다. `on`/`off` 는 현재 창에 적용되며, `ON`/`OFF` 는 기존 및 향후 모든 창에 적용됩니다.  
* **Incl** — **버튼 3** 을 사용해서 `<...>` 인클루드 파일을 열 때 사용할 보조 디렉터리를 추가합니다. 인수를 지정하지 않으면 현재 목록을 표시합니다.  
* **Local** — 네이티브 Plan 9는 Acme 고유의 네임스페이스/환경 그룹에서 명령을 실행합니다. Unix/plan9port는 인식되지만 아무런 효과가 없습니다.  

### Process-related

* **Kill** — 인자에 명시된 Acme에서 시작한 명령에 킬 신호를 보냅니다.  
* **Send** — 선택한 텍스트나 snarf 버퍼를 본문 끝에 추가합니다. 주로 `win` 명령과 함께 사용됩니다.  
* **ID** — 창의 ID 번호를 표시합니다.  

## Pipe-style command prefixes

이들은 **별도의 내장 명령어가 아닙니다!!**. 이 문자들 중 하나가 앞에 붙은 일반 셸 명령어이며, **2번 버튼** 을 눌러 실행됩니다. 이 명령어들은 **본문에서 선택된 텍스트** 를 대상으로 작동합니다. 

* **`< command`** — 선택 영역을 명령어의 표준 출력으로 대체합니다.  
* **`> command`** — 선택 영역을 명령어의 표준 입력으로 내보냅니다. 선택 영역 자체는 대체되지 않습니다.  
* **`| command`** — 선택한 텍스트를 명령어를 통해 파이프 처리합니다. 즉, 선택한 텍스트를 표준 입력(stdin)으로 내보내고, 그 자리를 표준 출력(stdout)으로 대체합니다.  

예시:

* `|sort`
* `|fmt`
* `<date`
* `>lp`

각 명령을 **버튼 2** 를 눌러 실행합니다. 명령의 출력 및 오류는 창의 디렉터리 컨텍스트에 따라 적절한 `+Errors` 창으로 전송됩니다. 


## Button 3 actions: open, go to, and search

**버튼 3** 을 누르면 Acme는 마우스가 가리키는 텍스트를 문맥에 따라 해석합니다. 

* 기존 창 이름 → 해당 창으로 이동합니다. 
* 기존 파일 이름 → 필요한 경우 새 창에서 해당 파일을 엽니다. 
* `<u.h>` 같은 인클루드 파일 → `Incl` 로 추가된 디렉터리를 포함해서 인클루드 디렉터리를 검색합니다. 
* `:` 으로 시작하는 텍스트 → 현재 창에서 sam 스타일의 주소로 처리합니다. 예: `:127`, `:/regexp/` 
* `file.c:27` 같은 텍스트 → 파일을 열고 해당 주소로 이동합니다. 
* 그 외의 모든 경우 → 현재 창 본문에서 문자 그대로의 텍스트를 검색합니다. **3번 버튼** 을 반복해서 클릭하면 다음 일치 항목으로 이동합니다. **Shift** 키를 누른 상태에서 클릭하면 검색 방향은 반대로 바뀝니다. 


## Mouse chords

Acme는 몇 가지 다중 버튼 동작을 지원합니다. 

* **버튼 1** 을 누른 상태로 텍스트를 선택한 다음, **버튼 2** 를 누르면 → **Cut** 가 실행됩니다. 
* **버튼 1** 을 누른 상태로 텍스트를 선택한 다음, **버튼 3** 을 누르면 → **Paste** 가 실행됩니다. 
* **버튼 1** 을 누른 상태로 **버튼 2를 누른 다음 버튼 3** 을 누르면 → 파일을 수정하지 않고 **Snarf** 가 실행됩니다. 


## Extra argument chord for commands

**버튼 2** 로 실행되는 명령어는 **2-1 조합** 을 사용해서 추가 인수를 지정할 수 있습니다. 명령어 텍스트에서 **버튼 2** 를 누른 상태에서, 인수 텍스트에서 **버튼 1** 을 클릭하면 해당 텍스트를 인수로 추가합니다. `Look` 명령을 예시로 들겠습니다. 

예시:

* `Look` 을 가리킵니다.
* **버튼 2** 를 누른 상태로 유지합니다.
* **버튼 1** 로 원하는 검색 텍스트를 클릭합니다.

이는 `Look Text` 명령을 실행하는 것과 동일합니다. 


## External shell commands

**버튼 2** 로 실행된 텍스트가 인식 가능한 내장 명령어가 **아닐** 경우, Acme는 이를 셸 명령어로 실행합니다. 표준 출력 및 표준 오류는 디렉터리별 `+Errors` 창으로 전송됩니다. 셸은 `$acmeshell` 환경 변수로 제어되며, 기본값은 `rc` 입니다. 


## Win

`Win` 명령은 **지원 프로그램** 이며, 앞서 언급한 내장 Acme 명령어 중 하나는 아닙니다. 이 프로그램은 새로운 Acme 창을 생성하고 그 안에서 명령어를 실행하며, 기본값은 `$SHELL` 환경 변수로 설정되고 해당 창이 터미널 창과 비슷한 방식으로 작동합니다. `Win` 창에서 **버튼 2** 를 눌러 텍스트를 실행하면 `Send` 와 유사한 동작을 보입니다. 


## Practical mini-reference

다음은 대부분의 사용자가 자주 사용하는 기능들입니다:

* **다음 리터럴 검색**— **버튼 1** 을 눌러 텍스트를 선택한 다음, **버튼 3** 을 누릅니다. 
* **정규식 검색** — `:/re/` 를 입력한 다음, **버튼 3** 을 누릅니다. 
* **줄로 이동** — `:123` 을 입력한 후 **버튼 3** 을 누릅니다. 
* **선택 영역에 셸 필터로 적용** — `|sort` 를 입력한 후 **버튼 2** 를 누릅니다. 
* **선택 영역을 명령어 출력으로 대체** — `<date` 를 입력한 후 **2번 버튼** 을 누릅니다. 
* **선택 영역을 명령어의 표준 입력(stdin)으로 전송** — `>lp` 를 입력한 후 **2번 버튼** 을 누릅니다. 
* **파일 저장** — `Put` 에서 **버튼 2** 를 누릅니다. 
* **파일 다시 불러오기** — `Get` 에서 **버튼 2** 를 누릅니다. 
* **`file.c` 파일 27번째 줄 열기** — `file.c:27` 에서 **버튼 3** 을 누릅니다. 

한 가지 중요한 제한 사항: **`Edit` 명령은 sam 명령어를 사용합니다!!**. sam은 Acme 내에 내장된 별도의 편집 언어입니다. 여기서는 sam 명령어 전체를 나열하지 않았습니다.
