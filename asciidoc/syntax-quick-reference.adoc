== Paragraphs

.단락
[#ex-normal]
----
Paragraphs don't require special markup in AsciiDoc.
A paragraph is defined by one or more consecutive lines of text.
Line breaks within a paragraph are not displayed.

Leave at least one empty line to begin a new paragraph.
----

중요: 대상이 `https:`와 같은 URL 스키마로 시작할 경우 `link:` 매크로 접두사는 _필요하지_ 않습니다.
URL 스키마 자체가 암시적인 매크로 접두사 역할을 합니다.

주의: 링크 텍스트에 쉼표가 포함되어 있고 그 뒤에 하나 이상의 명명된 속성이 오는 경우, 해당 텍스트를 큰따옴표로 묶어야 합니다.
그렇지 않으면 텍스트가 쉼표에서 잘리게 되며(나머지 텍스트는 속성 구문 분석에 포함됩니다).

.공백 및 특수 문자가 포함된 URL
----
link:++https://example.org/?q=[a b]++[URL with special characters]

https://example.org/?q=%5Ba%20b%5D[URL with special characters]
----

.상대 경로 파일 링크
----
link:index.html[Docs]
----

.Windows UNC 경로를 사용한 링크
----
link:\\server\share\whitepaper.pdf[Whitepaper]
----

== 문서 헤더

xref:document:header.adoc[문서 헤더]는 선택 사항입니다.
헤더에는 빈 줄이 포함되어서는 안 되며, 본문과는 최소 한 줄의 빈 줄로 구분되어야 합니다.

.제목
----
= Document Title

This document provides...
----

.제목 및 저자 정보
----
= Document Title
Author Name <author@email.org>

This document provides...
----

.제목, 저자 정보 및 개정 정보
----
= Document Title
Author Name <author@email.org>; Another Author <a.author@email.org>
v2.0, 2019-03-22

This document provides...
----

중요: xref:document:author-line.adoc[저자 정보]가 없으면 xref:document:revision-line.adoc[수정 내역]을 사용할 수 없습니다.

.속성 항목이 포함된 문서 헤더
----
= Document Title
Author Name <author@email.org>
v2.0, 2019-03-22
:toc:
:homepage: https://example.org

This document provides...
----

[#section-titles]
== 섹션 제목

문서 유형이 `article`(기본값)인 경우, 문서에는 0단계 섹션 제목(`=`)이 하나만 있을 수 있으며, 이는 문서 제목(즉, doctitle)입니다.

.기사 섹션 수준
[#ex-article]
----
= Document Title (Level 0)

== Level 1 Section Title

=== Level 2 Section Title

==== Level 3 Section Title

===== Level 4 Section Title

====== Level 5 Section Title

== Another Level 1 Section Title
----

.<<ex-article>> 결과 보기
[%collapsible.result]
====
// the float style is required to create standalone (non-section) headings
[float]
= Document Title (Level 0)

[float]
== Level 1 Section Title

[float]
=== Level 2 Section Title

[float]
==== Level 3 Section Title

[float]
===== Level 4 Section Title

[float]
====== Level 5 Section Title

[float]
== Another Level 1 Section Title
====

`book` 문서 유형은 추가적인 레벨 0 섹션 제목을 가질 수 있으며, 이는 xref:sections:parts.adoc[parts]로 해석됩니다.
적어도 하나의 파트가 존재하면 문서는 암묵적으로 다중 파트 책으로 간주됩니다.

.책의 섹션 수준
----
= Document Title (Level 0)

== Level 1 Section Title

= Level 0 Section Title (Part)

== Level 1 Section Title

=== Level 2 Section Title

==== Level 3 Section Title

===== Level 4 Section Title

====== Level 5 Section Title

= Another Level 0 Section Title (Part)
----

////
xref:sections:title-links.adoc#link[sectlinks]::
문서 속성 `sectlinks`가 설정되면 섹션 제목이 자체 링크가 됩니다.
이 기능을 통해 독자는 해당 섹션을 쉽게 북마크할 수 있습니다.

xref:sections:title-links.adoc#anchor[sectanchors]::
문서 속성 `sectanchors`가 설정되면, 마우스를 올렸을 때 섹션 제목 앞에 떠 있는 섹션 아이콘 앵커가 나타납니다.
이 기능을 통해 독자는 섹션을 쉽게 북마크할 수 있는 또 다른 방법을 이용할 수 있습니다.
섹션 제목 앵커가 올바르게 렌더링되려면 스타일시트의 지원이 필요합니다.
////

== 자동 목차

.문서의 목차 활성화
----
= 문서 제목
Doc Writer <doc.writer@email.org>
:toc:
----

목차`'의 xref:toc:title.adoc[title], xref:toc:levels.adoc[표시되는 섹션 깊이], xref:toc:position.adoc[위치]는 사용자 정의가 가능합니다.

== 포함

.문서 부분 포함
----
= Reference Documentation
Lead Developer

This is documentation for project X.

\include::basics.adoc[]

\include::installation.adoc[]

\include::example.adoc[]
----

.태그가 지정된 영역이나 줄 단위로 내용 포함
----
// selects lines between tag::definition[] and end::definition[] lines
\include::filename.txt[tag=definition]

\include::filename.txt[lines=5..10]
----

.URL에서 내용 포함
----
\include::https://raw.githubusercontent.com/asciidoctor/asciidoctor/main/README.adoc[]
----

경고: URL에서 콘텐츠를 포함하는 것은 잠재적으로 위험할 수 있으므로, 안전 모드가 SECURE 이상인 경우 이 기능은 비활성화됩니다.
안전 모드가 SECURE 미만인 경우, AsciiDoc 프로세서가 URL에서 콘텐츠를 읽을 수 있도록 `allow-uri-read` 속성도 설정해야 합니다.

인접한 두 목록을 강제로 분리하려면 두 번째 목록 위에 빈 속성 목록(예: `[]`)을 추가하거나, 첫 번째 목록 뒤에 빈 줄을 삽입한 다음 줄 주석을 추가하면 됩니다.
줄 주석을 사용할 경우, 다른 작성자들에게 이것이 목록 구분자 역할을 한다는 힌트를 주기 위해 `//-`를 사용하는 것이 관례입니다.

== 이미지

xref:macros:images-directory.adoc[imagesdir 속성]을 사용하면 모든 이미지 매크로에 이미지 경로를 직접 하드코딩하지 않아도 됩니다.
이 속성의 값은 절대 경로, 상대 경로 또는 기본 URL일 수 있습니다.
이미지 대상이 상대 경로인 경우, 속성의 값이 앞에 추가됩니다(즉, `imagesdir` 속성의 값을 기준으로 상대 경로로 해석됩니다).
이미지 대상이 URL이나 절대 경로인 경우, 속성의 값은 앞에 추가되지 않습니다.

.블록 이미지 매크로
[#ex-image-blocks]
----
image::sunset.jpg[]

image::sunset.jpg[Sunset]

.A mountain sunset
[#img-sunset,caption="Figure 1: ",link=https://www.flickr.com/photos/javh/5448336655]
image::macros:sunset.jpg[Sunset,200,100]

image::https://asciidoctor.org/images/octocat.jpg[GitHub mascot]
----

.<<ex-image-blocks>>의 결과 보기
[%collapsible.result]
====
image::sunset.jpg[]

image::sunset.jpg[Sunset]

.A mountain sunset
[#img-sunset,caption="Figure 1: ",link=https://www.flickr.com/photos/javh/5448336655]
image::macros:sunset.jpg[Sunset,200,100]

image::https://asciidoctor.org/images/octocat.jpg[GitHub mascot]
====

매크로에서 `image` 키워드 뒤에 콜론이 두 개(예: `image::`) 있으면 블록 이미지(그림)를 나타내고, 콜론이 하나(예: `image:`) 있으면 인라인 이미지를 나타냅니다.
(모든 매크로는 이 패턴을 따릅니다).
텍스트 줄 안에 이미지를 배치해야 할 때는 인라인 이미지를 사용합니다.
그 외의 경우에는 블록 형식을 사용하는 것이 좋습니다.

.임베드
----
= Document Title
:data-uri:
----

`data-uri` 속성이 설정되면, 문서 내의 모든 이미지(경고 아이콘 포함)가 {url-data-uri}[데이터 URI] 형태로 문서에 임베드됩니다.
`-a data-uri`를 사용하여 명령줄 인수로 전달할 수도 있습니다.

[참고]
====
xref:directives:include-with-indent.adoc[indent 속성]은 xref:directives:include-tagged-regions.adoc[태그가 지정된 영역]이나 xref:directives:include-lines.adoc[줄]을 통해 소스 코드를 포함할 때 자주 사용됩니다.

indent 값이 0보다 큰 경우, 먼저 블록의 선행 들여쓰기가 제거된 후, 이 값과 동일한 열 수만큼 블록이 들여쓰기됩니다.

== 구분 기호가 있는 블록 더 보기

== 표

.제목, 두 열, 헤더 행, 두 개의 내용 행이 있는 표
[#ex-header-row]
----
.Table Title
|===
|Column 1, Header Row |Column 2, Header Row <.>
<.>
|Cell in column 1, row 1
|Cell in column 2, row 1

|Cell in column 1, row 2
|Cell in column 2, row 2
|===
----
<.> `cols` 속성이 지정되지 않은 경우, 열의 수는 첫 번째 (비어 있지 않은) 줄에 있는 셀 구분자의 개수와 같습니다.
<.> 표의 시작 부분에서 비어 있지 않은 줄 바로 뒤에 빈 줄이 올 경우, 첫 번째 줄의 셀은 표 헤더로 승격됩니다.

.<<ex-header-row>>의 결과 보기
[%collapsible.result]
====
[caption=“표 1. ”]
.Table Title
|===
|Column 1, Header Row |Column 2, Header Row

|Cell in column 1, row 1
|Cell in column 2, row 1

|Cell in column 1, row 2
|Cell in column 2, row 2
|===
====

.두 개의 열, 헤더 행, 그리고 두 행의 내용으로 구성된 표
[#ex-cols]
----
[%header,cols=2*] <.>
|===
|Name of Column 1
|Name of Column 2

|Cell in column 1, row 1
|Cell in column 2, row 1

|Cell in column 1, row 2
|Cell in column 2, row 2
|===
----
<.> `cols` 속성의 `+*+`는 반복 연산자입니다.
이는 나머지 열에 대해 열 지정 내용을 반복한다는 의미입니다.
이 경우, 기본 서식을 2개의 열에 걸쳐 반복 적용합니다.
헤더의 셀이 한 줄로 정의되지 않은 경우, `cols` 속성을 사용하여 테이블의 열 수를 설정하고, `%header` 옵션(또는 `options=header` 속성)을 사용하여 첫 번째 행을 테이블 헤더로 지정해야 합니다.

.<<ex-cols>>의 결과 보기
[%collapsible.result]
====
[%header,cols=2*]
|===
|Name of Column 1
|Name of Column 2

|Cell in column 1, row 1
|Cell in column 2, row 1

|Cell in column 1, row 2
|Cell in column 2, row 2
|===
====

== 대체 문자 이스케이프

.백슬래시
[#ex-slash]
----
In /items/\{id}, the id attribute isn't replaced.
The curly braces around it are preserved.

\*Stars* isn't displayed as bold text.
The asterisks around it are preserved.

\&sect; appears as an entity reference.
It's not converted into the section symbol (&#167;).

\=> The backslash prevents the equals sign followed by a greater
than sign from combining to form a double arrow character (=>).

\[[Word]] is not interpreted as an anchor.
The double brackets around it are preserved.

[\[[Word]]] is not interpreted as a bibliography anchor.
The triple brackets around it are preserved.

\((DD AND CC) OR (DD AND EE)) is not interpreted as a flow index term.
The double brackets around it are preserved.

The URL \https://example.org isn't converted into an active link.
----
