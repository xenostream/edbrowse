== asciidoc이란

`asciidoc` 은 Markdown 같은 경량 마크업 언어 중 하나로, 웹 페이지 등을 일반 텍스트 형태로 작성할 수 있다(파일 확장자는 `.adoc`).


== asciidoc을 사용하게 된 경위

지금까지 Word로 기능 사양서 등을 작성했지만, Word는 매우 무겁고, 수정 위치를 파악하기 어렵고, 여러 사람이 동시에 수정하는 것도 번거로워서 Word 사용을 그만두고 싶어졌다. 그래서 “경량 마크업 언어” 를 사용하기로 했는데, 가장 대중적인? Markdown 을 사용해 보니 다음과 같은 제약 사항들 때문에 아무래도 좀 아쉽다...

* 표에서 셀을 병합할 수 없다
* 표의 셀 내에서 글머리 기호를 사용할 수 없다
* 목차를 만들 수 없다
* 글자에 색을 입힐 수 없다
* 위 사항들을 해결하려면 플러그인이나 마크다운 변형 버전 이것저것...

그래서 마크다운보다 표현 방법이 풍부한 `asciidoc` 을 사용해 보고, 실제로 사용한 후 특징과 과제를 정리해 보았다.


== asciidoctor, asciidoctor-pdf란

asciidoctor:: asciidoc 파일을 HTML 파일로 변환하는 Ruby 기반 도구
asciidoctor-pdf:: asciidoc 파일을 PDF 파일로 변환하는 Ruby 기반 도구

== 환경 구축(Windows)

=== asciidoctor, asciidoctor-pdf 설치

ruby(2.2 이상) 설치

https://rubyinstaller.org/downloads/

명령 프롬프트에서 다음 명령을 실행

 gem install asciidoctor             # asciidoctor 설치
 gem install --pre asciidoctor-pdf   # asciidoctor-pdf 설치
 gem install coderay                 # 코드 구문 강조 표시용
 gem install asciidoctor-pdf-cjk     # PDF 변환 시 레이아웃 깨짐 문제 해결
 gem install asciidoctor-diagram     # PlantUML 등의 다이어그램 사용


=== asciidoc 파일을 HTML, PDF로 변환

HTML 파일 변환

 asciidoctor test.adoc

=> test.html이 생성됩니다

PDF 파일 변환

 asciidoctor-pdf test.adoc

=> test.pdf이 생성됩니다

여러 파일을 한꺼번에 변환

 asciidoctor *.adoc
 asciidoctor-pdf *.adoc
 asciidoctor-pdf-cjk나 asciidoctor-diagram을 사용할 경우(-r 옵션 추가)
 asciidoctor -r asciidoctor-pdf-cjk -r asciidoctor-diagram test.adoc
 asciidoctor-pdf -r asciidoctor-pdf-cjk -r asciidoctor-diagram test.adoc

// 앞뒤에 공백이 없는 경우, ##로 하면 됩니다

=== 속성을 상수처럼 지정하기

asciidoc에는 미리 설정된 많은 속성(attribute)이 있으며, 이와 별도로 속성을 설정할 수도 있다.

속성은 `:속성명:` 으로 선언하고, `{속성명}` 으로 참조할 수 있다.

예를 들어, 다른 링크 주소 등 상수처럼 사용하고 싶은 경우, 직접 설정해 두면 편리하다.

.attribute.adoc
[source,asciidoc]
----
// 다른 팀의 앱 이름
:other-app-name: 호게 툴
// 다른 팀의 API 사양서
:other-app-api-doc-path: ../../other_app/api/index.html

{other-app-name}의 link:{other-app-api-doc-path}[API 사양서]
image.png
----


=== 조건에 따라 표시·숨기기

`ifdef ~ endif` 구문을 사용하면 가능. 이를 통해 팀용·고객 제출용 등으로 구분할 수 있음

표시하지 않는 경우(env-external 속성이 없음)

env-external은 예시이며, 값은 무엇이든 상관없음

.invisible.adoc
[source,asciidoc]
----
ifdef::env-external[]
  이 문장은 고객용입니다
endif::[]
표시할 경우(env-external 속성이 있는 경우)
visible.adoc
:env-external:

ifdef::env-external[]
  이 문장은 고객용입니다
endif::[]
----



=== 명령줄에서 속성 전달하기

앞서 설명한 env-external 경우처럼, adoc 내에 기술하지 않고 조건에 따라 값을 변경하고 싶은 경우, 명령줄에서 속성을 전달할 수도 있습니다

 asciidoctor -a env-external test.adoc

속성명뿐만 아니라 값도 전달하고 싶은 경우, `속성명=값` 형식으로 지정한다

이미 adoc 파일에 동일한 속성이 기술되어 있는 경우, 명령줄에서 전달한 값이 우선 적용된다

 asciidoctor -a toc-title=목차 test.adoc

=== 파일 불러오기

`include::` 를 사용하면 다른 파일을 불러올 수 있다 adoc 파일이 커져서 분할하고 싶을 때나, csv나 소스 코드 등 adoc과는 별개의 파일을 관리하고 싶을 때 유용하다

.include.adoc
[source,asciidoc]
-----
// adoc 파일 불러오기
include::other.adoc

// csv를 테이블로 불러오기
[format=“csv”]
|===
include::_includes/other.csv[]
|===

== asciidoctor-pdf의 문제점

=== 글자 색상을 변경할 수 없음

==== 「※」나 「①」이 표시되지 않음

기본 글꼴에 ‘※’ 나 ‘①’ 이 포함되어 있지 않다. fonts 폴더에 ‘※’ 나 ‘①’ 이 포함된 글꼴 파일을 넣으면 된다.

HTML(※나 ①이 표시됨)
image.png

PDF(※나 ①가 표시되지 않음)
image.png

해결책으로는 ‘※’ 나 ‘①’ 이 포함된 글꼴을 사용하는 것이다.

다음은 IPA 글꼴을 사용할 경우의 절차

IPA 글꼴 다운로드(여기서는 P 고딕 다운로드)

다운로드한 zip 파일 내에 있는 ipagp.ttf 파일을 pdf-fontsdir로 지정된 폴더에 넣는다

.pdf-font.adoc
[source,asciidoc]
----
// PDF 변환 시 글꼴 지정
// 지정하지 않을 경우, 기본값으로 ↓가 적용된다 (ruby2.4 + 64비트 Windows OS)
// C:\Ruby24-x64\lib\ruby\gems\2.4.0\gems\asciidoctor-pdf-1.5.0.alpha.16\data\fonts
:pdf-fontsdir: ./_pdf_fonts

// PDF 변환 시 스타일 지정
// 지정하지 않을 경우, 기본값으로 ↓가 적용됩니다 (Ruby 2.4 + 64비트 Windows OS)
// C:\Ruby24-x64\lib\ruby\gems\2.4.0\gems\asciidoctor-pdf-1.5.0.alpha.16\data\themes\default-theme.yml
:pdf-style: ./_pdf_themes/default-theme.yml
----

:pdf-style:로 지정한 yml 파일을 다음과 같이 수정한다

.default-theme.yml
[source,asciidoc]
----
font:
  catalog:
    IPA PGothic:           # 추가 부분
      normal: ipagp.ttf    # 추가 부분
      bold: ipagp.ttf      # 추가 부분
      italic: ipagp.ttf    # 추가 부분
      bold_italic: ipagp.ttf # 추가 부분
base:
  font_family: IPA PGothic # 변경 부분
----
