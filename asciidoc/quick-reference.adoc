= AsciiDoc 구문 빠른 참조

[IMPORTANT]
====
이 페이지의 예제는 내장된 HTML 변환기가 생성한 출력 결과를 보여줍니다. AsciiDoc 변환기는 PDF, EPUB, DocBook과 같은 다른 출력 형식을 생성할 때 이에 상응하는 출력 결과를 생성해야 합니다.
====

= Section titles

문서 유형이 ‘기사’(기본값)인 경우, 문서에는 레벨 0 섹션 제목(=)이 하나만 포함될 수 있으며, 이는 문서 제목(즉, doctitle)입니다.

*예 22. 기사의 섹션 레벨*

[source,asciidoc]
----
= Document Title (Level 0)

== Level 1 Section Title

=== Level 2 Section Title

==== Level 3 Section Title

===== Level 4 Section Title

====== Level 5 Section Title

== Another Level 1 Section Title
----

.예제 22의 결과 보기
[%collapsible]
======
[NOTE]
====
= Document Title (Level 0)

== Level 1 Section Title

=== Level 2 Section Title

==== Level 3 Section Title

===== Level 4 Section Title

====== Level 5 Section Title

== Another Level 1 Section Title
====
======

‘책’ 문서 유형에는 추가적인 레벨 0 섹션 제목이 포함될 수 있으며, 이러한 제목은 ‘파트’로 해석됩니다. 파트가 하나 이상 존재하면 해당 문서는 암묵적으로 다중 파트 책으로 간주됩니다.

===== Level 4 Section Title

====== Level 5 Section Title

= Another Level 0 Section Title (Part)
----

*예 28. URL의 콘텐츠 포함하기*

[source,asciidoc]
----
include::https://raw.githubusercontent.com/asciidoctor/asciidoctor/main/README.adoc[]
----

[WARNING]
====
URL의 콘텐츠를 포함하는 것은 잠재적으로 위험할 수 있으므로, 안전 모드가 SECURE 이상인 경우 이 기능은 비활성화됩니다. 안전 모드가 SECURE 미만인 경우, AsciiDoc 프로세서가 URL의 콘텐츠를 읽을 수 있도록 하려면 allow-uri-read 속성도 설정해야 합니다.
====

====
목록은 다른 블록과 구분하기 위해 앞뒤에 빈 줄이 있어야 합니다. 인접한 두 목록을 강제로 분리하려면 두 번째 목록 위에 빈 속성 목록(예: [])을 추가하거나, 첫 번째 목록 뒤에 빈 줄을 삽입한 다음 줄 주석을 추가하면 됩니다. 줄 주석을 사용할 경우, 다른 작성자들에게 이것이 목록 구분자 역할을 한다는 것을 알리기 위해 //-를 사용하는 것이 관례입니다.
====

= Images

imagesdir 속성을 사용하면 모든 이미지 매크로에 이미지 파일의 공통 경로를 직접 하드코딩하지 않아도 됩니다. 이 속성의 값은 절대 경로, 상대 경로 또는 기본 URL일 수 있습니다. 이미지 대상이 상대 경로인 경우, 이 속성의 값이 앞에 추가됩니다(즉, imagesdir 속성의 값을 기준으로 상대 경로가 해결됩니다). 이미지 대상이 URL이나 절대 경로인 경우, 이 속성의 값은 앞에 추가되지 않습니다.

image::https://asciidoctor.org/images/octocat.jpg[GitHub mascot]
