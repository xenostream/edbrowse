== Introduction of VBScript - Visual Basic Scripting Edition

이 장은 VBScript 언어에 대한 간략한 소개를 제공합니다. 여기서 다루는 주제는 VBScript란 무엇인지, VBScript 호스트 환경에는 어떤 것들이 있는지, Internet Explorer(IE), Internet Information Services(IIS) 및 Windows Script Host(WSH) 내에서 VBScript 코드를 실행하는 방법 등입니다.

* VBScript란 무엇인가?
* Internet Explorer 10 이하 버전에서 VBScript 사용하기
* Internet Explorer 11에서 VBScript 사용하기
* 인터넷 정보 서비스(IIS)에서 VBScript 사용하기
* WSH(Windows Script Host)에서 VBScript 사용하기
* Microsoft Access에서 Visual Basic 사용하기
* VBScript 및 지원 환경

핵심 내용:

* VBScript(Visual Basic Scripting Edition)는 Visual Basic 언어에서 파생된 스크립팅 언어입니다.
* VBScript 코드는 VBScript 호스트 환경에서 실행되어야 합니다.
* IE(Internet Explorer) 10 이하 버전은 웹 페이지에서 클라이언트 측 스크립팅을 수행할 수 있는 VBScript 호스트 환경을 제공합니다.
* IE 11에서는 웹 페이지에서 VBScript 코드를 실행하기 위해 설정 변경이 필요합니다.
* Edge 및 기타 웹 브라우저는 웹 페이지에서 VBScript 코드를 지원하지 않습니다.
* IIS(Internet Information Services)는 웹 페이지에서 서버 측 스크립팅을 수행할 수 있는 VBScript 호스트 환경을 제공합니다.
* WSH(Windows Script Host)는 독립 실행형 스크립트 코드 파일을 실행할 수 있는 VBScript 호스트 환경을 제공합니다.


=== What Is VBScript?

이 섹션은 “Windows 시스템용 스크립트 언어” 인 `VBScript` 에 대해 간략히 소개합니다. VBScript를 사용하면 Internet Explorer 및 웹 페이지 스크립팅을 위한 Internet Information Services(IIS) 같은 다양한 호스트 환경에서 실행될 스크립트 코드를 작성할 수 있습니다.

VBScript - VBScript(Visual Basic Scripting Edition)는 Microsoft에서 Windows 운영 체제를 위해 개발한 스크립트 언어입니다.

VBScript 코드는 호스트 환경 내에서 실행해야 합니다. 이를 통해 호스트 환경과 상호 작용해서 일부 프로그래밍 작업을 수행할 수 있습니다.

호스트 환경은 일반적으로 다음과 같은 기능을 제공합니다.

* VBScript 소스 코드를 입력할 수 있는 특정 방법을 제공합니다.
* VBScript 핵심 사양에 정의된 몇 가지 기본 객체를 제공합니다.
* 코드가 호스트 애플리케이션과 상호 작용할 수 있는 특정 객체를 제공합니다.
* 코드가 특정 운영 체제 리소스에 액세스할 수 있는 추가 객체를 제공합니다.

VBScript 호스트 환경의 예

* Internet Explorer (IE) - HTML 문서를 화면에 렌더링하는 동안 실행될 VBScript 코드를 HTML 문서에 포함할 수 있습니다. 이를 “클라이언트 측 스크립팅” 이라고 합니다.
* Internet Information Services (IIS) - 웹 서버에서 클라이언트 컴퓨터로 전달할 HTML 문서를 가져오는 동안 실행될 VBScript 코드를 HTML 문서에 포함할 수 있습니다. 이를 “서버 측 스크립팅” 이라고 합니다.
* Windows Script Host (WSH) - 스크립트 파일에 VBScript 코드를 포함시켜 Windows 운영 체제에서 직접 실행할 수 있게 해줍니다.

VBScript는 사실 Microsoft의 Visual Basic 프로그래밍 언어의 제한된 변형입니다. 따라서 VBScript는 Visual Basic과 동일한 언어 구문을 사용합니다.

Visual Basic은 독립형 Windows 응용 프로그램을 개발하는 데 사용할 수 있습니다. 또한 Visual Basic은 Microsoft Access 같은 다른 Windows 응용 프로그램용 매크로 코드를 작성하는 데도 사용할 수 있습니다.

VBScript 버전 이력:

2009년, VBScript 5.8
2007년, VBScript 5.7
2002년, VBScript 5.6
1999년, VBScript 5.0
1998년, VBScript 4.0
1998년, VBScript 3.0
1997년, VBScript 2.0
1996년, VBScript 1.0

버전 이력에서 볼 수 있듯이, VBScript는 이제 수명 주기의 끝을 향해 가고 있습니다. 마이크로소프트는 IE를 대체하는 브라우저인 “Edge에서 더 이상 VBScript를 지원하지 않을 것” 이라고 발표했습니다.

하지만 구형 브라우저와 구형 Windows 시스템은 여전히 VBScript를 사용할 수 있습니다.


=== Using VBScript with Internet Explorer 10 or Older

이 섹션은 로컬 컴퓨터에서 Internet Explorer 10 이하 버전에서 실행되도록 HTML 문서에 VBScript 코드를 삽입하는 방법에 대한 튜토리얼 예제를 제공합니다.

인터넷 익스플로러(IE)는 웹 페이지를 보기 위한 웹 브라우저로 사용할 수 있는 마이크로소프트의 응용 프로그램입니다. IE는 또한 VBScript 호스트 환경을 지원하여, 웹 페이지(HTML 문서)의 소스 코드에 VBScript 코드를 삽입할 수 있게 해줍니다.

HTML 문서에 삽입된 VBScript 코드는 IE가 브라우저 창에서 HTML 문서를 렌더링하는 동안 실행됩니다. 스크립트 코드가 서버가 아닌 클라이언트 컴퓨터에서 실행되기 때문에 이를 클라이언트 측 스크립팅이라고도 합니다.

HTML 문서에 VBScript 코드를 추가하려면 “language=vbscript” 속성이 지정된 “script” 태그를 사용해야 합니다. “script” 태그 안에는 VB 문장을 원하는 만큼 넣을 수 있습니다. 다음은 HTML 문서에 VBScript 코드를 추가하는 구문입니다:

... (HTML 태그)
<script language=vbscript>
   ... (VB 문장)
</script>
... (HTML 태그)

이제 HTML 문서에 첫 번째 VBScript 코드를 작성해 보겠습니다.

1. 메모장을 열어 다음 HTML 문서를 입력하세요:

<html>
<body>
<script language="vbscript">
   document.write(“Hello world! - VBScript”)
</script>
</body>
</html>

2. HTML 문서를 hello_vb.html로 저장하세요.

3. IE 10으로 HTML 문서를 열어보세요. IE 창에 다음과 같은 메시지가 표시되어야 합니다.

Hello world! - VBScript

축하합니다. IE에서 지원하는 호스트 환경용 VBScript 코드를 성공적으로 작성하셨습니다!

여기서 일어난 일은 다음과 같습니다.

    HTML 문서인 hello_vb.html에 “script” 태그를 추가했습니다.
    “script” 태그 안에 간단한 VBScript 코드를 포함시켰습니다.
    이 VBScript 코드는 “document.write” 함수를 호출하는데, 이 함수는 HTML 문서에 텍스트 문자열을 삽입하기 위해 IE 호스트 환경에서 제공하는 함수입니다.
    IE를 실행하여 hello_vb.html을 확인한 결과, 예상한 대로 정확히 표시되었습니다.

다음 사항에 유의하십시오:

    IE 11을 사용하는 경우, 다음 튜토리얼에 따라 ActiveX 지원을 활성화해야 합니다.
    Edge, Chrome, Firefox와 같은 다른 웹 브라우저를 사용하는 경우, 해당 브라우저들은 VBScript를 지원하지 않으므로 빈 페이지가 표시됩니다.


=== Using VBScript with Internet Explorer 11

이 섹션에서는 VBScript 코드가 포함된 웹 페이지를 불러오기 위해 IE 11에서 스크립트 실행을 활성화하고 ‘Edge’ 모드를 비활성화하는 방법에 대한 튜토리얼 예제를 제공합니다.

© 2026 Dr. Herong Yang. 모든 권리 보유.

IE(Internet Explorer) 11의 VBScript 지원 기능은 기본적으로 비활성화되어 있습니다. IE 11에서 VBScript 코드를 실행하려면 두 가지 설정을 변경해야 합니다.

1. 스크립트 및 ActiveX 컨트롤 활성화 - IE 11에서 스크립트 및 ActiveX 컨트롤 실행이 비활성화되어 있는 경우, 다음과 같은 메시지 상자가 표시됩니다.

Internet Explorer에서 이 웹 페이지의
스크립트 또는 ActiveX 컨트롤 실행을 제한했습니다.
                      [ 차단된 콘텐츠 허용 ]

“차단된 콘텐츠 허용”을 클릭하면 IE 11에서 웹 페이지에 포함된 VBScript 코드를 실행할 수 있습니다.

![20261031_205423.jpg](images/20261031_205423.jpg)  
Enable Script Running in IE 11

2. “Edge” 모드 비활성화 - 기본적으로 IE 11은 VBScript를 지원하지 않는 “Edge” 모드로 실행됩니다. 따라서 “Edge” 모드를 비활성화해야 합니다:

F12 키를 눌러 IE 개발자 도구 창을 엽니다.

“에뮬레이션” 탭을 클릭합니다.

“문서 모드” 설정을 “Edge”에서 “10”으로 변경합니다.

왼쪽 상단 모서리에 있는 “에뮬레이션 설정 유지” 아이콘을 클릭하여 변경 사항을 저장합니다.

![20261031_205501.jpg](images/20261031_205501.jpg)  
Disable Edge Mode in IE 11

이 두 가지 변경 사항을 적용하면 IE 11에서 VBScript 코드를 실행할 수 있게 될 것입니다.


=== Using VBScript with Internet Information Services

이 섹션에서는 서버 컴퓨터의 IIS(Internet Information Services)에서 실행되도록 HTML 문서에 VBScript 코드를 삽입하는 방법에 대한 튜토리얼 예제를 제공합니다.

© 2026 Dr. Herong Yang. 모든 권리 보유.

Internet Information Services(IIS)는 웹(HTTP) 서버 및 이메일(SMTP) 서버와 같은 인터넷 서비스를 제공하고 관리하는 Microsoft 제품입니다.

또한 IIS는 VBScript 호스트 환경을 지원하여, 웹 페이지의 소스 코드(HTML 문서)에 VBScript 코드를 삽입할 수 있게 해줍니다. HTML 문서에 삽입된 VBScript 코드는 IIS가 웹 서버에서 HTML 문서를 가져와 클라이언트 컴퓨터로 전달하는 과정에서 실행됩니다. 스크립트 코드가 클라이언트 컴퓨터가 아닌 서버 컴퓨터에서 실행되기 때문에 이를 ‘서버 측 스크립팅’이라고도 합니다.

IIS가 실행할 수 있도록 HTML 문서에 VBScript 코드를 추가하는 한 가지 방법은 ASP(Active Server Pages) 기술을 사용하는 것입니다. Windows 시스템에 IIS가 설치되어 있다면, 다음 단계를 따라 IIS에서 간단한 VBScript 코드를 실행할 수 있습니다.

1. 제어판으로 이동한 다음, 관리 도구를 선택하고 인터넷 서비스 관리자로 이동합니다. 그런 다음 '기본 웹 사이트'를 마우스 오른쪽 버튼으로 클릭하고 속성을 선택합니다.

2. 속성 대화 상자에서 ‘홈 디렉터리’ 탭을 클릭한 다음, ‘구성’ 버튼을 클릭합니다.

3. 구성 대화 상자에서 [앱 매핑] 탭을 클릭한 다음, 매핑 영역에서 다음 줄이 표시되는지 확인하여 IIS에서 ASP를 지원하는지 확인하십시오.

확장자   실행 파일 경로                     Verb

.asp        c:\winnt\system32\inetsrv\asp.dll   GET,HEAD,POST,TRACE

4. 다음 hello.asp 파일을 만드십시오.

<%@ language="vbscript"%>
<html><body>
<%
response.write(“Hello world! - VBScript in IIS”)
%>
</body></html>

5. hello.asp 파일을 IIS가 HTML 문서를 처리하는 디렉터리인 \inetpub\wwwroot에 복사합니다.

=== "Variant" - Data Type and Subtypes

이 섹션에서는 VBScript의 데이터 유형인 ‘Variant’에 대해 간략히 소개하고, 그 하위 유형인 byte, integer, long, single, double, currency, string, Boolean, date, object, error, empty 및 null을 나열합니다.

© 2026 Dr. Herong Yang. 모든 권리 보유.

흥미롭게도 VBScript에는 “Variant”라는 단 하나의 데이터 유형만 존재하며, 사용 방법에 따라 다양한 종류의 데이터를 저장하는 데 사용할 수 있습니다. 이는 VBScript가 느슨한 타입 지정(loose typing) 또는 동적 타입 지정(dynamic typing) 언어임을 의미합니다.

VBScript의 모든 데이터는 동일한 데이터 유형인 “Variant”로 간주되지만, 그 값에 따라 특정 데이터 범주로 분류될 수 있습니다. 이러한 데이터 범주를 하위 유형이라고 합니다.

VBScript는 다음 13가지 데이터 하위 유형을 지원합니다:

    Byte: 1바이트를 사용하여 0부터 255까지의 정수를 표현합니다.
    Integer: 2바이트를 사용하여 -32,768부터 32,767까지의 부호 있는 정수를 표현합니다.
    Long: 4바이트를 사용하여 -2,147,483,648부터 2,147,483,647까지의 부호 있는 정수를 표현합니다.
    Single: 4바이트를 사용하여 부동소수점 형식의 실수를 표현하며, 음수의 경우 -3.402823e38부터 -1.401298e-45까지, 양수의 경우 1.401298e-45부터 3.402823e38까지의 범위를 가집니다.
    Double: 8바이트를 사용하여 실수를 부동소수점 형식으로 표현하며, 음수의 경우 -1.79769313486232e308부터 -4.94065645841247e-324까지, 양수의 경우 4.94065645841247e -324에서 1.79769313486232e308까지의 양수 범위를 나타냅니다.
    통화: 8바이트를 사용하여 -922,337,293,685,477.5808부터 922,337,293,685,477.5807까지의 범위를 갖는 십진법 형식의 실수를 표현합니다.
    문자열: 문자당 1바이트를 사용하여 최대 약 20억 자까지의 문자열을 표현합니다.
    부울(Boolean): 2바이트를 사용하여 True와 False라는 두 가지 부울 값을 표현합니다.
    날짜(Date): 8바이트를 사용하여 100년 1월 1일부터 9999년 12월 31일까지의 날짜를 표현합니다.
    빈 값(Empty): 아직 어떤 값도 할당되지 않은 변수를 나타내는 특수한 하위 유형입니다.
    Null: null 값이 할당된 변수를 나타내는 특수한 하위 유형입니다.
    객체: 객체에 대한 참조를 나타내는 특수 하위 유형입니다.
    오류: 오류 번호를 나타내는 특수 하위 유형입니다.

=== Data Literals

이 섹션에서는 데이터 하위 유형 리터럴에 대해 간략히 소개합니다. 정수(Integer), 장정수(Long), 단정밀도 실수(Single), 이중정밀도 실수(Double), 문자열(String), 부울(Boolean), 날짜(Date), 빈 값(Empty) 및 null에 대한 데이터 리터럴 예제를 제공합니다.

© 2026 Dr. Herong Yang. 모든 권리 보유.

데이터 리터럴: VBScript 문에서 특정 하위 유형의 데이터 값을 나타내는 코드 조각입니다. VBScript는 다양한 하위 유형의 데이터 리터럴에 대해 다음과 같은 구문 규칙을 제공합니다.

    바이트(Byte) 리터럴 - 존재하지 않습니다. 따라서 VBScript 코드에 바이트 값을 입력할 방법이 없습니다. 바이트 값이 필요한 경우, CByte() 변환 함수를 사용하여 정수 값을 바이트 값으로 변환할 수 있습니다(예: CByte(7)).
    정수 리터럴 - -8, 0, 777과 같이 10진수 형식으로 표현된, 정수 값 범위 내의 부호 있는 정수입니다.
    롱 리터럴 - -888888 및 777777과 같이 10진수 형식으로 표현된, 롱 값 범위 내에 있지만 정수 값 범위 밖의 부호 있는 정수입니다.
    Single 리터럴 - 존재하지 않습니다. 따라서 VBScript 코드에 Single 값을 입력할 방법은 없습니다. Single 값이 필요한 경우, 변환 함수 CSng()를 사용하여 실수 값을 Single 값으로 변환할 수 있습니다(예: CSng(0.00314159e30)).
    Double: 리터럴 - 소수점 및/또는 지수 부분이 포함된 과학 표기법의 Double 값 범위 내의 부호 있는 실수(예: 9.99, 0.00314159e30, 333.333e200).
    통화 리터럴 - 존재하지 않습니다. 따라서 VBScript 코드에 통화 값을 입력할 방법이 없습니다. 통화 값이 필요한 경우, CCur() 변환 함수를 사용하여 소수 값을 통화 값으로 변환할 수 있습니다(예: CCur(9.99)).
    문자열 리터럴 - “Hello”와 같이 큰따옴표(")로 묶인 일련의 문자입니다.
    부울 리터럴 - True와 False라는 두 가지 키워드 중 하나입니다.
    날짜 리터럴 - # 기호로 묶인 날짜 및/또는 시간을 나타내는 문자열입니다(예: #31-Dec-1999#).
    빈 리터럴 - 키워드: Empty
    Null 리터럴 - 키워드: Null
    객체 리터럴 - 확실하지 않습니다. 나중에 알아보겠습니다.
    오류 리터럴 - 확실하지 않습니다. 나중에 알아보겠습니다.

다양한 데이터 하위 유형의 리터럴에 대한 더 많은 예제는 다음 섹션을 참조하십시오.



=== Data Literal Examples

이 섹션에서는 Integer, Long, Double, String, Boolean, Date, Empty 및 Null의 다양한 하위 유형에 대한 데이터 리터럴을 작성하는 방법에 대한 튜토리얼 예제를 제공합니다.

© 2026 Dr. Herong Yang. 모든 권리 보유.

이제 Internet Explorer가 제공하는 호스트 환경에서 실행될 수 있도록 HTML 문서 내에 간단한 VBScript 코드를 작성해 보겠습니다.

텍스트 편집기를 실행하고 다음 파일인 data_literal.html을 입력하십시오:

[source,html]
----
<html>
<body>
<!-- data_literal.html
 - Copyright (c) 1998 HerongYang.com. All Rights Reserved.
-->
<pre>
<script language="vbscript">
   document.writeln("7=" & (7) & " : " & TypeName(7))
   document.writeln("CByte(7)=" & (CByte(7)) & " : " _ 
      & TypeName(CByte(7)))
   document.writeln("777=" & (777) & " : " & TypeName(777))
   document.writeln("777777=" & (777777) & " : " & TypeName(777777))
   document.writeln("9.99=" & (9.99) & " : " & TypeName(9.99))
   document.writeln("CSng(9.99)=" & (CSng(9.99)) & " : " _ 
      & TypeName(CSng(9.99)))
   document.writeln("0.00314159e30=" & (0.00314159e30) & " : " _ 
      & TypeName(0.00314159e30))
   document.writeln("333.333e200=" & (333.333e200) & " : " _ 
      & TypeName(333.333e200))
   document.writeln("CCur(9.99)=" & (CCur(9.99)) & " : " _ 
      & TypeName(CCur(9.99)))
   document.writeln("""Hello""=" & ("Hello") & " : " _ 
      & TypeName("Hello"))
   document.writeln("TRUE=" & (TRUE) & " : " & TypeName(TRUE))
   document.writeln("#31-Dec-1999#=" & (#31-Dec-1999#) & " : " _ 
      & TypeName(#31-Dec-1999#))
   document.writeln("Empty=" & (Empty) & " : " & TypeName(Empty))
   document.writeln("Null=" & (Null) & " : " & TypeName(Null))
</script>
</pre>
</body>
</html>
----

이 VBScript 예제에 대한 몇 가지 참고 사항:

    “document” 객체의 “writeln()” 함수는 HTML 문서에 텍스트 문자열을 출력하는 데 사용됩니다.
    문자열 연결 연산자인 “&”는 여러 문자열을 하나로 연결하는 데 사용됩니다.
    특수 함수인 TypeName()은 지정된 값의 하위 유형을 표시하는 데 사용됩니다.
    문장 연속 문자(_)는 여러 줄을 하나의 문장으로 연결하는 데 사용됩니다.

이 VBScript 예제를 IE에서 열면 다음과 같은 결과가 표시됩니다:

 7=7 : Integer
 CByte(7)=7 : Byte
 777=777 : Integer
 777777=777777 : Long
 9.99=9.99 : Double
 CSng(9.99)=9.99 : Single
 0.00314159e30=3.14159E+27 : Double
 333.333e200=3.33333E+202 : Double
 CCur(9.99)=9.99 : Currency
 "Hello"=Hello : String
 TRUE=True : Boolean
 #31-Dec-1999#=12/31/1999 : Date
 Empty= : Empty
 Null= : Null

이 출력은 이전 섹션에서 설명한 데이터 리터럴 규칙에 대한 우리의 이해와 일치합니다:

    “7=7 : Integer”는 작은 정수 값이 Byte 값으로 인식되지 않음을 보여줍니다.
    “CByte(7)=7 : Byte”는 CByte()가 Byte 값을 반환함을 보여줍니다.
    “777777=777777 : Long”은 큰 정수 값이 Long 값으로 인식됨을 보여줍니다.
    “9.99=9.99 : Double”은 작은 실수 값이 Single 값으로 인식되지 않음을 보여줍니다.
    “CSng(9.99)=9.99 : Single”은 CSng()가 Single 값을 반환함을 보여줍니다.
    “0.00314159e30=3.14159E+27 : Double”은 실수가 표준 부동소수점 형식으로 정규화된다는 것을 보여줍니다.
    “CCur(9.99)=9.99 : Currency”는 CCur()가 Currency 값을 반환한다는 것을 보여줍니다.
    “TRUE=True : Boolean”은 키워드가 대소문자를 구분하지 않음을 나타냅니다. 키워드 “TRUE”는 “True”와 동일합니다.
    “#31-Dec-1999#=12/31/1999 : Date”는 여러 가지 날짜 형식이 지원됨을 나타냅니다. dd-MMM-yyyy와 mm/dd/yyyy 모두 유효합니다.
    “Empty= : Empty”는 문자열 연결 연산에서 Empty 값이 빈 문자열로 변환됨을 나타냅니다.
    “Null= : Null”는 문자열 연결 연산에서 Null 값이 빈 문자열로 변환됨을 나타냅니다.



=== String Data Literals

이 섹션에서는 쌍따옴표로 묶인 문자열 데이터 리터럴을 작성하는 규칙에 대해 설명합니다.

© 2026 Dr. Herong Yang. 모든 권리 보유.

이전 섹션에서, 문자열 데이터 리터럴은 “Hello”와 같이 쌍따옴표(")로 묶인 일련의 문자라는 것을 배웠습니다.

하지만 String 데이터 리터널에 관한 규칙이 하나 더 있습니다.

    문자열에 큰따옴표(“)가 포함되어 있다면, 그 큰따옴표 앞에는 또 다른 큰따옴표를 붙여 (”")와 같이 표기해야 합니다.

문자열 리터널에 큰따옴표를 포함하는 방법을 보여드리기 위해 다음과 같은 스크립트(string_literal.html)를 준비했습니다.

</body>

=== Date and Time Data Literals

이 섹션에서는 해시 기호(#)로 묶인 날짜 및 시간 리터럴을 작성하는 규칙을 다룹니다. VBScript는 ISO 형식 및 미국 형식과 같은 여러 가지 날짜 문자열 형식을 지원합니다.

© 2026 Dr. Herong Yang. 모든 권리 보유.

이전 섹션에서, 날짜 리터럴은 해시 기호(#)로 묶인 날짜 및/또는 시간을 나타내는 문자열이라는 점을 배웠습니다.

다음은 날짜 및/또는 시간 리터럴을 작성하는 방법에 대한 자세한 내용입니다.

    #31-Dec-1999#와 같이 날짜 부분만 포함하여 날짜 리터럴을 작성할 수 있습니다.
    시간 부분만 포함하여 #21:26:00#과 같이 날짜 리터럴을 작성할 수 있습니다.
    날짜와 시간 부분을 모두 포함하여 #31-Dec-1999 21:26:00#과 같이 날짜 리터럴을 작성할 수 있습니다.
    또한 #1999-12-31 21:26:00#과 같이 ISO 형식으로 날짜 리터럴을 작성할 수도 있습니다.
    미국 형식으로 날짜 리터럴을 작성할 수도 있습니다(예: #12/31/1999 9:26:00 PM#).
    밀리초가 포함된 날짜 리터럴은 작성할 수 없습니다(예: #31-Dec-1999 21:26:00.123#).

다음은 다양한 형식으로 날짜와 시간을 작성하는 방법에 대한 튜토리얼 예시입니다:

'   document.writeln("#21:26:00.123# = " & (#21:26:00.123#))
   document.writeln("#31-Dec-1999 21:26:00# = " _
      & (#31-Dec-1999 21:26:00#))

</pre>
</body>
</html>

== Arithmetic Operations

이 장에서는 VBScript 산술 연산에 대한 튜토리얼 예제와 설명을 제공합니다. 주요 내용으로는 8가지 산술 연산(덧셈(+), 뺄셈(-), 단항 부호 반전(-), 곱셈(*), 나눗셈(/), 정수 나눗셈(\), 나머지(Mod), 지수 연산(^))에 대한 소개와 각 산술 연산의 작동 원리에 대한 자세한 규칙이 포함됩니다.

    산술 연산 소개

    “+” - 산술 덧셈 연산

    “-” - 산술 뺄셈 연산

    “*” - 산술 곱셈 연산

    “/” - 산술 나눗셈 연산

    “\” - 산술 정수 나눗셈 연산

    “Mod” - 산술 나머지 연산

    “^” - 산술 지수 연산

요약:

    VBScript에서는 8가지 산술 연산이 지원됩니다: 덧셈(+), 뺄셈(-), 단항 부정(-), 곱셈(*), 나눗셈(/), 정수 나눗셈(\), 나머지(Mod), 지수 연산(^).
    산술 연산의 피연산자는 숫자 값이거나 숫자 값으로 변환될 수 있는 다른 값이어야 합니다.
    반환 값의 하위 유형은 피연산자의 값 범위와 하위 유형에 따라 결정됩니다.


=== Introduction of Arithmetic Operations

이 섹션에서는 VBScript에서 지원하는 산술 연산, 즉 덧셈, 뺄셈, 곱셈, 나눗셈, 나머지, 지수 연산에 대해 간략히 소개합니다.

© 2026 Dr. Herong Yang. 모든 권리 보유.

VBScript는 8가지 산술 연산을 지원합니다:

    덧셈 (+): 두 피연산자의 수학적 합을 반환합니다.
    뺄셈 (-): 첫 번째 피연산자에서 두 번째 피연산자를 뺀 결과를 반환합니다.
    단항 부호 반전 (-): 유일한 피연산자의 부호가 반전된 값을 반환합니다.
    곱셈 (*): 첫 번째 피연산자와 두 번째 피연산자를 곱한 결과를 반환합니다.
    나눗셈 (/): 첫 번째 피연산자를 두 번째 피연산자로 나눈 결과를 반환합니다.
    정수 나눗셈 (\): 첫 번째 피연산자를 두 번째 피연산자로 나눈 결과를 반환합니다. 연산 전에 두 피연산자 모두 정수 값으로 반올림됩니다. 결과 값에서 소수 부분은 제거됩니다.
    모듈러스(나머지라고도 함) (Mod): 첫 번째 피연산자를 두 번째 피연산자로 나눈 나머지를 반환합니다. 연산 전에 두 피연산자 모두 정수 값으로 반올림됩니다.
    제곱 (^): 첫 번째 피연산자를 두 번째 피연산자로 제곱한 값을 반환합니다.

간단한 산술 연산을 보여드리기 위해, 다음 스크립트인 arithmetic_operation.html을 작성했습니다:

   document.writeln("- 3 = " & (- 3))
   document.writeln("9 * 9 = " & (9 * 9))
   document.writeln("20 / 3 = " & (20 / 3))
   document.writeln("20 \ 3 = " & (20 \ 3))

=== "+" - Arithmetic Addition Operation

이 섹션에서는 VBScript에서 산술 덧셈 연산이 어떻게 작동하는지에 대한 세부 규칙과 튜토리얼 예제를 제공합니다.

© 2026 Dr. Herong Yang. 모든 권리 보유.

다음은 산술 연산 중 덧셈에 관한 세부 규칙입니다:

    산술 덧셈 연산에는 덧셈 연산자 “+”가 사용됩니다.
    산술 덧셈 연산을 수행하려면 피연산자 중 적어도 하나는 Byte, Integer, Long, Single 또는 Double과 같은 숫자 하위 유형이어야 합니다.
    피연산자가 숫자 하위 유형이 아닌 경우, 숫자 하위 유형으로 변환됩니다.
    부울(Boolean) 하위 유형은 덧셈 연산에서 숫자 하위 유형으로 간주됩니다. “True”는 숫자 값 -1을 나타냅니다. “False”는 수치 값 0을 나타냅니다.
    빈(Empty) 하위 유형은 덧셈 연산에서 수치 하위 유형으로 간주됩니다. “Empty”는 수치 값 0을 나타냅니다.
    덧셈 연산에 문자열(String) 값이 사용되면, 해당 값은 Double 값으로 파싱됩니다. 파싱 과정에서 오류가 발생하면, 덧셈 연산에서 “Type mismatch” 런타임 오류가 발생합니다.
    반환 값은 첫 번째 피연산자와 두 번째 피연산자의 수치적 합계입니다.
    반환 값의 하위 유형은 반환 값의 범위와 피연산자의 하위 유형에 따라 결정됩니다.

다음은 산술 덧셈 연산 규칙이 어떻게 작동하는지 보여주는 튜토리얼 예제입니다:

[source,html]
----
<html>
<body>
<!-- addition_operation.html
 - Copyright (c) 1998 HerongYang.com. All Rights Reserved.
-->
<pre>
<script language="vbscript">
   document.writeln("7+7=" & (7+7) & " : " & TypeName(7+7))
   document.writeln("7+777777=" & (7+777777) & " : " _ 
      & TypeName(7+777777))
   document.writeln("7+9.99=" & (7+9.99) & " : " & TypeName(7+9.99))
   document.writeln("7+333.333e200=" & (7+333.333e200) & " : " _
      & TypeName(7+333.333e200))
   document.writeln("7+""7""=" & (7+"7") & " : " & TypeName(7+"7"))
'  document.writeln("7+""7Hello""=" & (7+"7Hello") & " : " _
'     & TypeName(7+"7Hello"))
   document.writeln("7+True=" & (7+True) & " : " & TypeName(7+True))
   document.writeln("7+False=" & (7+False) & " : " _
      & TypeName(7+False))
   document.writeln("True+False=" & (True+False) & " : " _
      & TypeName(True+False))
   document.writeln("7+Empty=" & (7+Empty) & " : " _ 
      & TypeName(7+Empty))
</script>
</pre>
</body>
</html>
----

다음은 이 VBScript 예제 스크립트의 실행 결과입니다:

----
7+7=14 : Integer
7+777777=777784 : Long
7+9.99=16.99 : Double
7+333.333e200=3.33333E+202 : Double
7+"7"=14 : Double
7+True=6 : Integer
7+False=7 : Integer
True+False=-1 : Integer
7+Empty=7 : Integer
----

출력 결과는 산술 덧셈 연산의 몇 가지 규칙을 확인해 줍니다:

    “7+7=14 : Integer”는 결과가 작은 값이고 두 피연산자 모두 정수 값이므로, 결과가 정수 값임을 보여줍니다.
    “7+777777=777784 : Long”는 결과가 정수 값의 범위를 벗어난 큰 값이므로, 결과가 Long 값임을 보여줍니다.
    “7+9.99=16.99 : Double”은 두 번째 피연산자가 Double 값이므로 결과가 Double 값임을 나타냅니다. “9.99”는 Double 리터럴입니다. 이전 장의 데이터 리터럴 섹션을 참조하십시오.
    “7+‘7’=14 : Double”은 두 번째 피연산자가 Double 값이므로 결과가 Double 값임을 나타냅니다. 문자열이 숫자 값으로 구문 분석될 때는 Double 값이 반환됩니다.
    (7+“7Hello”)에 대한 문장은 문자열 “7Hello”가 Double 값으로 구문 분석될 수 없기 때문에 주석 처리되어 있습니다.
    “True+False=-1 : Integer”는 VBScript가 True를 -1로, False를 0으로 인식함을 보여줍니다.

== Regular Expression Pattern Match and Replacement

이 장은 VBScript의 정규식 지원에 대한 튜토리얼 예제와 참고 사항을 다룹니다. 주요 주제로는 ‘RegExp’ 클래스 및 객체, 정규식 및 일치 옵션 플래그 설정, 일치 및 치환을 위한 패턴 적용, `MatchCollection` 및 `SubMatches` 컬렉션 객체 확인, 정규식 패턴 일치 및 치환 예제 등이 포함됩니다.

* 정규식 지원을 위한 “RegExp” 클래스 및 객체
* “MatchCollection” 및 “SubMatches” 컬렉션 객체
* “Set oRegExp = New RegExp” - RegExp 객체 생성
* 정규 표현식 일치 및 치환 예제

핵심 내용:

* “RegExp” 는 정규 표현식 패턴 일치 및 치환을 지원하는 내장 클래스입니다.
* “Set oRegExp = New RegExp” 는 새로운 “RegExp” 객체를 생성합니다.
* “oRegExp.Pattern” 은 정규 표현식 패턴이 포함됩니다.
* “oRegExp.Global” 은 여러 번의 일치를 수행해야 함을 나타냅니다.
* “oRegExp.IgnoreCase” 는 문자 일치 시 대소문자를 구분하지 않아야 함을 나타냅니다.
* “oRegExp.Test()” 는 일치하는 항목이 발견되면 `True` 를 반환합니다.
* “oRegExp.Replace()” 는 일치하는 부분이 대체된 문자열의 복사본을 반환합니다.
* “oRegExp.Execute()” 는 “Match” 객체들로 구성된 `MatchCollection` 컬렉션을 반환합니다.
* “Match” 객체는 일치의 길이, 위치 및 문자열이 포함됩니다.
* 또한 “Match” 객체는 하위 일치 문자열들로 구성된 `SubMatches` 컬렉션이 포함됩니다.


=== "RegExp" Class and Object for Regular Expression Support

이 섹션은 정규식을 사용한 패턴 일치에 활용되는 ‘RegExp’ 클래스와 객체에 대해 설명합니다. `oRegExp.execute(string)` 은 `MatchCollection` 컬렉션 객체를 반환합니다.

VBScript는 정규식 기능을 지원하기 위해 “RegExp” 라는 내장 클래스를 제공합니다.

정규식 작업을 수행하려면 다음 구문을 사용해서 `RegExp` 객체를 생성해야 합니다.

[source,vbscript]
----
Set oRegExp = New RegExp
----

변수에 객체를 할당하려면 “Set” 문을 사용해야 한다는 점에 유의합니다.

그러면 `RegExp` 객체인 `oRegExp` 에서 지원하는 속성과 메서드를 사용할 준비가 됩니다:

* `oRegRex.Pattern` - 검색 패턴을 나타내는 정규 표현식 문자열을 포함하는 `String` 속성입니다.
* `oRegRex.Global` - 전역 검색 플래그를 나타내는 `Boolean` 속성입니다. 이 플래그가 켜져 있으면 전체 문자열에 대해 검색이 여러 번 적용됩니다.
* `oRegRex.IgnoreCase` - 대소문자 구분 없이 검색하는 플래그를 나타내는 `Boolean` 속성입니다. 이 플래그가 켜져 있으면 대소문자를 구분하지 않고 검색이 수행됩니다.
* `oRegRex.Test(string)` - 주어진 문자열에서 패턴 일치 항목이 발견되면 `True` 를 반환하는 메서드입니다.
* `oRegRex.Execute(string)` - `Match` 객체 목록을 포함하는 `MatchCollection` 컬렉션 객체를 반환하는 메서드입니다. 각 `Match` 객체는 주어진 문자열에서 발견된 패턴 일치 항목을 나타냅니다.
* `oRegRex.Replace(string, replacement)` - 주어진 문자열의 복사본을 반환하며, 발견된 각 패턴 일치 항목을 대체 문자열로 바꾼 것입니다.

`Match` 객체는 다음과 같은 속성이 있습니다.

* `oMatch.Length` - 이 패턴 매치의 문자 수를 나타내는 정수 속성입니다.
* `oMatch.FirstIndex` - 문자열 내에서 이 패턴 매치가 발견된 위치를 나타내는 정수 속성입니다.
* `oMatch.Value` - 문자열 내에서 발견된 이 매치를 나타내는 `String` 속성입니다. “Value” 속성은 기본 속성입니다. 따라서 `Match` 객체가 `String` 컨텍스트에서 사용될 경우 “Value” 속성이 반환됩니다.
* `oMatch.SubMatches` - `String` 목록을 포함하는 `SubMatches` 컬렉션 속성입니다. 각 문자열은 하위 패턴 일치 결과를 나타냅니다.

`MatchCollection` 및 `SubMatches` 객체는 “컬렉션 객체” 라는 점에 유의합니다. 이들은 모든 컬렉션 객체와 동일한 속성과 메서드를 공유합니다. 자세한 내용은 다음 섹션을 참조합니다.


=== "MatchCollection" and "SubMatches" Collection Objects

이 섹션은 `MatchCollection` 과 `SubMatches` 두 가지 컬렉션 객체에 대해 설명합니다. 모든 컬렉션 객체는 `Count` 속성과 `Item(i)` 메서드를 공통으로 가지고 있습니다.

앞서 `MatchCollection` 과 `SubMatches` 객체가 “컬렉션 객체” 라고 언급한 바 있습니다. 모든 컬렉션 객체는 다음과 같은 동일한 속성과 메서드를 공유합니다:

* `oCollection.Count` - 이 컬렉션에 포함된 항목의 수를 나타내는 정수형 속성입니다.
* `oCollection.Item(i)` - 이 컬렉션의 i번째 위치에 있는 항목을 반환하는 메서드입니다. “Item(i)” 메서드는 컬렉션 객체의 기본 메서드로 정의되어 있습니다. 따라서 메서드 이름을 생략하고 이 메서드를 호출할 수 있습니다. 예를 들어, `oCollection(0)` 은 `oCollection.Item(0)` 과 동일하며, 이 컬렉션의 첫 번째 항목을 가리킵니다.

컬렉션 객체는 “For Each” 문에서 배열처럼 사용할 수 있습니다:

[source,vbscript]
----
For Each e In oCollection
   ... = ... e ... ' e는 현재 항목을 나타냅니다
End For
----

`oRegExp.Execute(string)` 메서드에서 반환된 `MatchCollection` 객체인 `oMatches` 에 위의 속성과 메서드를 적용하면, 다음과 같은 흥미로운 예제를 이해할 수 있을 것입니다.

* `oMatches.Count` - `Match` 객체의 개수.
* `oMatches.Item(0)` - 첫 번째 `Match` 객체.
* `oMatches(0)` - 첫 번째 `Match` 객체.
* `oMatches(1).SubMatches` - 두 번째 `Match` 객체의 `SubMatches` 컬렉션 객체.
* `oMatches(1).SubMatches.Count` - 두 번째 `Match` 객체의 하위 일치 문자열 개수.
* `oMatches(1).SubMatches.Item(1)` - 두 번째 `Match` 객체의 두 번째 하위 일치 문자열.
* `oMatches(1).SubMatches(1)` - 두 번째 `Match` 객체의 두 번째 하위 일치 문자열.


=== "Set oRegExp = New RegExp" - Creating RegExp Objects

이 섹션은 `Set oRegExp = New RegExp` 라는 `Set` 문을 사용해서 새로운 `RegExp` 객체를 생성하는 방법을 설명합니다. `oRegExp.Global` 및 `oRegExp.IgnoreCase` 는 패턴 일치 옵션을 설정하는 데 사용됩니다.

패턴 일치 연산의 반환 객체 구조에 대해서는 충분히 다루었습니다. 이제 패턴 일치 연산을 어떻게 설정할 수 있는지 살펴보겠습니다:

1. `Set` 문을 사용해서 빈 RegExp 객체를 생성하고 이를 변수에 할당합니다:

[source,vbscript]
----
Dim oRegExp
Set oRegExp = New RegExp
----

여기서 `RegExp` 는 `RegExp` 클래스 이름이며, `New` 는 클래스에서 새로운 객체를 생성하는 연산자고, `oRegExp` 는 새로운 `RegExp` 객체를 담는 `Variant` 변수입니다.

2. 정규 표현식 규칙에 따라 정규 표현식 문자열을 일치 패턴으로 할당합니다. 다음은 정규 표현식의 몇 가지 예시입니다. 좀 더 많은 예시는 정규 표현식 설명서를 참조합니다:

[source,vbscript]
----
' “ee” 로 끝나는 모든 단어를 일치시키는 패턴.
' 하위 일치 항목은 정의되지 않았습니다.
oRegExp.Pattern = “\w+ee\s”

' 모든 이메일 주소를 일치시키는 패턴.
' 패턴에 3개의 하위 일치 항목이 정의되어 있습니다.
oRegExp.Pattern = “(\w+)@(\w+)\.(\w+)”
----

3. `Global` 및 `IgnoreCase` 일치 플래그를 설정합니다. 예시:

[source,vbscript]
----
' 전체 문자열에서 일치를 반복합니다.
oRegExp.Global = True

' 패턴 일치 시 대소문자를 구분하지 않습니다.
oRegExp.IgnoreCase = True
----

이제 `RegExp` 객체인 `oRegExp` 를 사용해서 다음 연산을 통해 주어진 문자열을 다시 일치시킬 준비가 되었습니다:

[source,vbscript]
----
' 패턴이 적어도 한 번 일치하면 True를 반환합니다.
bFound = oRegExp.Test(string)

' 일치하는 부분마다 대체된 주어진 문자열의 복사본을 반환합니다.
sCopy = oRegExp.Replace(string, replacement)

' 일치 결과를 포함하는 MatchCollection 객체를 반환합니다.
Set oMatches = oRegExp.Execute(string)
----


=== Example of Regular Expression Match and Replacement

이 섹션은 `RegExp` 객체를 사용해서 정규 표현식으로 패턴 일치 및 치환을 수행하는 방법에 대한 튜토리얼 예제를 제공합니다. 부분 일치에 대한 예제도 포함되어 있습니다.

이제 `RegExp` 객체를 사용해서 정규 표현식으로 패턴 일치를 수행하는 VBScript 예제를 살펴볼 준비가 되었습니다:

[source,html]
----
<html>
<body>

<script language="vbscript">
   Dim oRegExp
   Set oRegExp = New RegExp

   ' 모든 이메일 주소를 일치시키는 패턴.
   ' 패턴에 정의된 2개의 하위 일치 항목.
   oRegExp.Pattern = “(\w+)@(\w+)\.com”

   ' 전체 문자열에 대해 일치를 반복합니다.
   oRegExp.Global = True

   ' 패턴 일치 시 대소문자를 구분하지 않습니다.
   oRegExp.IgnoreCase = True

   Dim sString
   sString = “도움이 필요하시면 Me@HerongYang.com으로, ” _
      & “버그를 신고하시려면 Support@MicroSoft.COM으로 연락해 주세요.”

   bFound = oRegExp.Test(sString)
   document.writeln()
   document.writeln(“일치 항목 발견: ” & bFound)

   Dim sCopy
   sCopy = oRegExp.Replace(sString, “xxx@xxx.com”)
   document.writeln()
   document.writeln(“이메일 주소 교체됨: ” & sCopy)

   Dim oMatches
   Set oMatches = oRegExp.Execute(sString)
   document.writeln()
   document.writeln(“일치 항목 수: ” & oMatches.Count)
   For Each oMatch In oMatches
      document.writeln(“   길이 = ” & oMatch.Length)
      document.writeln(“   첫 번째 인덱스 = ” & oMatch.FirstIndex)
      document.writeln(“   값 = ” & oMatch.Value)

      For Each sSubMatch In oMatch.Submatches
          document.writeln(“      부분 일치 = ” & sSubMatch)
      Next
   Next
</script>

== WSH (Windows Script Host)

이 장은 WSH(_Windows Script Host_)에 대한 실습 예제와 참고 사항을 다룹니다. 중요 주제로는 옵션과 함께 WSH 명령어, cscript 및 wscript 실행하기, WSH 런타임 개체 요약, 입출력을 위한 StdIn 및 StdOut 객체 사용법, 스크립트 코드를 통해 시스템 명령어 실행하기, WSF 파일에서 스크립트 작업 정의하기 등이 포함됩니다.

* WSH(Windows Script Host)란 무엇인가?
* “cscript.exe/wscript.exe” 명령어의 버전 및 옵션
* VBScript 코드 파일 실행
* “WScript” 런타임 객체 계층 구조
* “oShell.Exec(cmd)” - 스크립트를 사용해서 시스템 명령 실행
* WSF - Windows 스크립트 파일 XML 형식

핵심 내용:

* WSH(Windows Script Host)는 VBScript 같은 스크립트 언어로 작성된 스크립트를 실행하는 “관리 도구” 입니다.
* WSH는 스크립트 코드가 로컬 시스템 환경과 상호 작용할 수 있도록 런타임 객체를 제공합니다.
* WSF(Windows Script File)는 스크립트 작업을 정의할 수 있는 XML 파일 형식입니다.
* 명령 창을 사용하거나 사용하지 않고 스크립트를 실행할 수 있도록 cscript.exe 와 wscript.exe 두 가지 WSH 명령이 제공됩니다.


=== What is WSH (Windows Script Host)?

이 섹션은 WSH(_Windows Script Host_)와 그 기능에 대해 설명합니다. WSH는 일반적인 관리 작업을 수행하기 위해 VBScript 코드를 실행하는 Windows 시스템 관리 도구입니다.

WSH(_Windows Script Host_)는 VBScript 엔진 및 JScript 엔진 같은 Windows Script 호환 스크립팅 엔진을 위한 “언어 독립적인 스크립팅 호스트” 입니다. WSH는 Windows 32비트 플랫폼에 간단하면서 강력하며 유연한 스크립팅 기능을 제공해서, Windows 데스크톱과 명령 프롬프트 모두에서 스크립트를 실행할 수 있게 해줍니다.

Windows Script Host는 로그온 스크립팅, 관리 스크립팅, 시스템 자동화 등 비-대화형 스크립팅 작업에 이상적입니다.

Windows 시스템의 일부로 설치되는 WSH는 다음과 같은 기능을 제공합니다:

* WSH는 CScript.exe 와 WScript.exe 두 가지 호스트로 제공됩니다.
* CScript.exe 호스트는 명령 창에서 표준 입력 및 출력 콘솔을 사용해서 스크립트를 실행합니다.
* WScript.exe 호스트는 명령 창 없이 GUI 스크립트를 실행합니다. 이 경우 표준 입력 및 출력 객체를 사용할 수 없습니다.
* 파일 및 폴더 관리, 네트워크 드라이브 매핑, 환경 변수 관리, 레지스트리 키 수정 같은 관리 작업을 위한 여러 런타임 개체가 제공됩니다.
* 다음과 같은 다양한 유형의 스크립트 파일 형식이 지원됩니다: `*.vbs` (VBScript 파일), `*.wsf` (Windows Script File).
** `.vbs` 파일(VBScript 파일)은 VBScript 문만 포함됩니다.
** `.wsf` 파일(Windows Script File)은 XML 파일 형식의 스크립트 코드가 포함됩니다.

Windows 시스템에서 제공되는 WSH 버전:

 WSH 5.812   Windows 10
 WSH 5.8     Windows 8
 WSH 5.8     Windows 7
 WSH 5.7     Windows Vista
 WSH 5.6     Windows XP

현재 사용 중인 Windows 시스템에서 WSH를 사용할 수 있는지 확인하려면 명령 프롬프트에서 “cscript /?” 명령을 실행합니다.

=== Running VBScript Code Files

이 섹션은 ‘cscript/wscript’ 명령어를 사용하거나 사용하지 않고 VBScript 파일을 실행하는 방법에 대한 튜토리얼 예제를 제공합니다.

이제 WSH를 사용해서 첫 번째 VBScript를 작성하고 실행하겠습니다.

다음과 같은 문장이 포함된 VBScript 예제 파일인 _Hello_Echo.vbs_ 를 만드세요.

[source,vbscript]
----
'  Hello_Echo.vbs
'- Copyright (c) 1998 HerongYang.com. All Rights Reserved.

   Set oArgs = WScript.Arguments
   If oArgs.Length = 0 Then WScript.Echo “Hello world!”
   For Each sArg In oArgs
      WScript.Echo “Hello ” & sArg
   Next
----

명령 프롬프트에서 다양한 방법으로 _Hello_Echo.vbs_ 를 실행합니다:

----
C:\herong>cscript Hello_Echo.vbs Herong Tom
Hello Herong
Hello Tom

C:\herong>wscript Hello_Echo.vbs Herong Tom
(“Hello Herong” 이 표시된 대화 상자)
(“Hello Tom” 이 표시된 두 번째 대화 상자)

C:\herong>cscript //h:cscript
이제 기본 스크립트 호스트가 “cscript.exe” 로 설정되었습니다.

C:\herong>Hello_Echo.vbs Herong Tom
Hello Herong
Hello Tom

C:\herong>cscript //h:wscript
이제 기본 스크립트 호스트가 “wscript.exe” 로 설정되었습니다.

C:\herong>Hello_Echo.vbs Herong Tom
(“Hello Herong” 이 표시된 대화 상자)
(“Hello Tom” 이 표시된 두 번째 대화 상자)
----

_Hello_Echo.vbs_ 는 다음 3가지 방법으로 실행할 수 있습니다:

* “cscript Hello_Echo.vbs ...” - 호스트 cscript.exe 를 사용해서 실행합니다.
* “wscript Hello_Echo.vbs ...” - 호스트 wscript.exe 를 사용해서 실행합니다.
* “Hello_Echo.vbs ...” - 기본 호스트(cscript.exe 또는 wscript.exe)를 사용해서 실행합니다. “cscript //h:...” 명령을 사용해서 기본 호스트를 변경할 수 있습니다.


=== "WScript" Runtime Object Hierarchy

이 섹션은 WSH 런타임 객체인 `WScript` 와 그 속성에 대해 설명합니다. `WScript.StdIn` 및 `WScript.StdOut` 을 사용하는 방법에 대한 튜토리얼 예제가 제공됩니다.

다른 스크립팅 환경 호스트와 마찬가지로, WSH는 VBScript 코드가 환경과 상호 작용할 수 있도록 몇 가지 유용한 런타임 객체를 제공합니다:

* `WScript` - 다른 WSH 객체들을 포함하는 WSH 런타임 계층 구조의 “루트 객체” 입니다. `WScript` 는 표준 입력 및 출력, 외부 COM 객체 연결 등 스크립트 실행 수준 정보에 접근할 수 있는 몇 가지 중요한 속성도 포함되어 있습니다.
* `WScript.Arguments` - 명령줄 인수를 컬렉션 형태로 나타내는 `WshArguments` 객체입니다.
* `WScript.CreateObject(“WSHController”)` - 새로운 `WshController` 객체를 생성해서 다른 스크립트 코드로 새로운 실행 스레드를 만들고 제어합니다.
* `WScript.CreateObject(“WSHController”).CreateScript(command_line, remote_machine)` - 새로운 실행 스레드로 실행될 새로운 `WshRemote` 객체를 생성합니다.
* `WScript.CreateObject(“WScript.Network”)` - 로컬 컴퓨터를 포함한 네트워크 리소스에 액세스하기 위해 새로운 `WshNetwork` 객체를 생성합니다.
* `WScript.CreateObject(“WScript.Shell”)` - 로컬 컴퓨터에서 명령을 실행하고 레지스트리 키를 관리하기 위해 새로운 `WshShell` 객체를 생성합니다.

`WScript` 객체의 `StdIn` 및 `StdOut` 속성을 사용하는 간단한 예제를 살펴보겠습니다:

[source,vbscript]
----
'  StdIn_StdOut.vbs
'- Copyright (c) 1998 HerongYang.com. All Rights Reserved.

   Dim StdIn, StdOut
   Set StdIn = WScript.StdIn
   Set StdOut = WScript.StdOut

   Dim cmd
   Do While True
      StdOut.WriteLine
      StdOut.WriteLine "Herong, what can I do for you?"
      cmd = StdIn.ReadLine
      If cmd = "Nothing" Then Exit Do
      StdOut.WriteLine "Sorry, I am not programmed to do that."
   Loop
----

이제 cscript.exe 를 사용해서 실행해 보세요:

----
C:\herong>cscript StdIn_StdOut.vbs

Herong, what can I do for you?
Make me rich
Sorry, I am not programmed to do that.

Herong, what can I do for you?
Make me happy
Sorry, I am not programmed to do that.

Script execution time was exceeded on script 
   "C:\herong\StdIn_StdOut.vbs".
Script execution was terminated.
----

코드는 제대로 작동했습니다. 하지만 실행 시간 제한으로 인해 중단되었습니다. 10분 동안 실행하려면 `//T:600` 같이 명령줄에서 좀 더 긴 시간 제한을 지정해서 실행해야 합니다:

[source,vbscript]
----
 cscript //T:600 StdIn_StdOut.vbs
----

또한 이 예제는 wscript.exe 호스트에서 실행할 수 없습니다! wscript.exe 호스트는 `StdIn` 및 `StdOut` 속성을 지원하지 않기 때문입니다. “wscript StdIn_StdOut.vbs” 를 실행하면 “핸들이 유효하지 않습니다” 라는 오류가 발생합니다.



=== "oShell.Exec(cmd)" - Running System Command with a Script

이 섹션은 VBScript 코드를 사용해서 시스템 명령을 실행하는 방법에 대한 튜토리얼 예제를 제공합니다. `WshScriptExec` 속성을 통해 명령의 출력 및 상태를 모니터링할 수 있습니다.

이전 섹션에서 언급한 것 같이, WSH는 시스템 관리 작업을 수행하기 위한 런타임 객체를 제공합니다.

다음은 `WshShell` 객체를 사용해서 시스템 명령을 실행하고 출력을 가져오는 튜토리얼 예제입니다:

[source,vbscript]
----
'  StdIn_StdOut.vbs
'- Copyright (c) 1998 HerongYang.com. All Rights Reserved.

   Dim oShell, oExec, sLine
   Set oShell = CreateObject("WScript.Shell")
   Set oExec = oShell.Exec("ping localhost")

'  Reading the output of the shell command thread
   Do While Not oExec.StdOut.AtEndOfStream
      sLine = oExec.StdOut.ReadLine
      WScript.StdOut.WriteLine "Output: " & sLine
      WScript.Sleep 10
   Loop

'  Waiting for the shell command thread to end
'  In case the output ends before the command
   Do While oExec.Status = 0
      WScript.Sleep 100
   Loop
----

=== WSF - Windows Script File XML Format

이 섹션은 WSF(Windows Script File) XML 형식에 대해 설명합니다. 하나의 WSF 파일에 서로 다른 스크립트 언어를 사용하는 여러 스크립트 작업을 정의할 수 있습니다.

WSH는 VBScript 코드 파일을 직접 실행할 수 있습니다. 하지만 .WSF(Windows Script File)라는 XML 파일 형식도 지원합니다. WSF 파일은 스크립트 작업을 정의하고 작업을 패키지로 묶을 수 있는 XML 구조를 제공합니다.

WSF는 다음과 같은 기본 XML 요소를 지원합니다.

* “package” - WSF 파일의 루트 요소입니다.
* “package.job” - job 요소는 “id” 속성을 사용해서 스크립트 작업을 정의합니다.
* “package.job.script” - script 요소는 “language” 속성에 지정된 언어로 된 스크립트 코드 세그먼트를 삽입합니다.

다음은 WSF 파일의 튜토리얼 예제입니다:

[source,xml]
----
<?xml version="1.0" encoding="UTF-8"?>
<package>
<!-- Windows_Script_File.vbs
 - Copyright (c) 1998 HerongYang.com. All Rights Reserved.
-->
   <job id="VBScriptJob">
      <script language="VBScript">
         WScript.Echo "Hello world! - VBScriptJob"
      </script>
   </job>

   <job id="JScriptJob">
      <script language="JScript">
         WScript.Echo("Hello world! - JScriptJob"); 
      </script>
   </job>
   
   <job id="MixedJob">
      <script language="VBScript">
         Dim sName
         sName = "MixedJob"
      </script>
      <script language="JScript">
         WScript.Echo("Hello world! - "+sName); 
      </script>
   </job>
</package>
----

이 WSF 파일에 정의된 작업은 아래와 같이 WSH 호스트를 통해 실행할 수 있습니다.

----
C:\herong>cscript //Job:VBScriptJob Windows_Script_File.wsf

Hello world! - VBScriptJob

C:\herong>cscript //Job:JScriptJob Windows_Script_File.wsf

Hello world! - JScriptJob

C:\herong>cscript //Job:MixedJob Windows_Script_File.wsf

Hello world! - MixedJob
----

다음 사항에 유의하시기 바랍니다.

* 첫 번째 작업을 제외하고, WSF 파일에 정의된 작업을 실행하려면 “//Job:...” 옵션을 반드시 사용해야 합니다.
* “JScript” 는 Microsoft 버전의 JavaScript입니다.
* “MixedJob” 은 서로 다른 언어로 작성된 여러 스크립트 코드 세그먼트를 함께 사용해서 단일 작업을 수행할 수 있음을 나타냅니다.
