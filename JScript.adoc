== What Is JScript?

"`JScript`" 는 ECMA 262 언어 사양을 마이크로소프트에서 구현한 것입니다. 이는 완전한 구현체일 뿐만 아니라, 마이크로소프트 인터넷 익스플로러의 기능을 활용하는 몇 가지 향상된 기능도 포함되어 있습니다. 이 자습서는 JScript를 시작하는 데 도움을 드리기 위해 마련되었습니다.


=== Easy to Use, Easy to Learn

JScript는 해석형 객체 기반 스크립팅 언어입니다. C++이나 Java 같은 본격적인 객체 지향 언어에 비해 기능은 적지만, JScript는 의도된 용도에는 충분히 강력한 성능을 발휘합니다.

JScript는 다른 언어의 축소판이 아니며(예를 들어, Java와는 간접적이고 먼 관계에 불과합니다), 어떤 언어의 단순화된 버전도 아닙니다. 하지만 한계가 있습니다. 예를 들어, JScript는 독립 실행형 애플리케이션을 작성할 수 없으며, 파일을 읽거나 쓰는 기능도 거의 없습니다. 게다가 JScript 스크립트는 웹 서버나 웹 브라우저 같은 인터프리터가 있어야만 실행될 수 있습니다.

JScript는 느슨한 타입 지정 언어입니다. 즉, 변수의 데이터형을 명시적으로 선언할 필요가 없습니다. 사실, JScript는 데이터형을 명시적으로 선언할 수조차 없습니다. 또한 대부분의 경우 JScript는 필요할 때 자동으로 변환을 수행합니다. 예를 들어, 숫자를 텍스트(문자열)로 구성된 항목에 더하면, 그 숫자는 텍스트로 변환됩니다.

이 튜토리얼의 나머지 부분은 JScript 기능에 대한 개요입니다. 언어 구현에 대한 자세한 내용은 언어 참조 문서를 참고합니다.

NOTE: 이 튜토리얼에 나오는 많은 예제의 코드는 실제 웹 페이지에서 볼 수 있는 코드보다 다소 직관적이고 간결하지 않습니다. 또한 대부분이 상당히 단순합니다. 여기서의 목적은 “개념을 명확히 설명하는 것” 이지, 최적의 코드 간결성이나 스타일을 보여주는 것이 아닙니다. 어쨌든, 코드를 작성한 지 6개월 지난 후에도 자신이 직접 읽고 쉽게 이해할 수 있는 코드를 작성하는 것은 결코 부끄러운 일이 아닙니다.   



== JScript Basics


=== Writing JScript Code

다른 많은 프로그래밍 언어와 마찬가지로, Microsoft JScript는 텍스트 형식으로 작성되며, 문, 관련 문들로 구성된 블록, 주석으로 구성됩니다. 문 내에서는 변수, 문자열이나 숫자 같은 즉시 데이터, 그리고 식을 사용할 수 있습니다.

==== Statements

JScript 코드 문은 한 줄에 하나 이상의 항목과 기호로 구성됩니다. 새 줄은 새로운 문으로 시작되지만, 문을 명시적으로 종료하는 것이 좋습니다. JScript의 종료 문자인 세미콜론(`;`)을 사용해서 문장을 종료할 수 있습니다.

[source,jscript]
----
aBird = “Robin”;
var today = new Date();
----

중괄호(`{...}`)로 둘러싸인 JScript 문들의 모음을 “블록” 이라 합니다. 문 블록은 예를 들어 함수나 조건문에서 사용됩니다.

다음 예제에서 첫 번째 문장은 5개의 문장으로 구성된 블록으로 이루어진 함수 정의를 시작합니다. 중괄호로 묶이지 않은 마지막 세 문장은 블록이 아니며, 함수 정의의 일부도 아닙니다.

[source,jscript]
----
function convert(inches)  {
    feet = inches / 12;            //  이 5개의 문장은 하나의 블록을 이룹니다.
    miles = feet / 5280;
    nauticalMiles = feet / 6080;
    cm = inches * 2.54;
    meters = inches / 39.37;
}
km = meters / 1000;               //  이 세 개의 문장은 블록에 속하지 않습니다.
kradius = km;
mradius = miles;
----


==== Comments

한 줄짜리 JScript 주석은 슬래시 두 개(`//`)로 시작합니다. 여러 줄로 이루어진 주석은 슬래시와 별표의 조합(`/*`)으로 시작하고, 그 반대 순서(`*/`)로 끝납니다.

[source,jscript]
----
aGoodIdea = “코드를 꼼꼼하게 주석 처리하세요.”;  //  이것은 한 줄짜리 주석입니다.

/*
이것은 앞선 코드 문장을 설명하는 여러 줄 주석입니다.

이 문장은 aGoodIdea 변수에 값을 할당합니다. 따옴표 사이에
포함된 이 값을 “리터럴” 이라 합니다. 리터럴은 정보를 명시적이고
직접적으로 포함하며, 정보를 간접적으로 참조하지 않습니다.
(따옴표는 리터럴의 일부가 아닙니다.)
*/

//  이것은 일련의 한 줄 주석으로 작성된 또 다른 여러 줄 주석입니다.
//  문장이 실행된 후에는 aGoodIdea 변수의 내용을
//  변수 이름을 사용해서 참조할 수 있습니다. 다음 문장과 같이, 문자열 리터럴을
//  aGoodIdea 변수에 연결해서 새로운 변수를 생성합니다.

var extendedIdea = aGoodIdea + “ 언제 그 기능이 무엇인지 파악해야 할지 알 수 없으니까요.”;
----


==== Assignments and Equality

JScript에서 등호(`=`)는 값을 할당하는 작업에 사용됩니다. 즉, JScript 코드 문은 다음과 같이 작성될 수 있습니다.

 anInteger = 3;

이는 “anInteger 변수에 값 3을 할당한다!” 또는 “anInteger 변수가 값 3을 갖는다” 는 의미입니다. 두 값이 같은지 비교하려면 등호 두 개(`==`)를 사용합니다. 이에 대한 자세한 내용은 ‘프로그램 흐름 제어’ 에서 다룹니다.


==== Expressions

JScript 식이란 부울 또는 숫자 식으로 읽을 수 있는 것을 말합니다. 식에는 “더한다” 같은 단어 대신 “+” 같은 기호가 포함됩니다. 값, 변수, 연산자 및 식의 유효한 조합은 모두 식을 구성합니다.

[source,jscript]
----
var anExpression = “3 * (4 / 5)”;
var aSecondExpression = “Math.PI * radius * 2”;
var aThirdExpression = aSecondExpression + “%” + anExpression;
var aFourthExpression = “(” + aSecondExpression + “) % (” + anExpression + “)”;
----


=== JScript Variables

Microsoft JScript는 스크립트에 값을 저장하기 위해 변수를 사용합니다. 변수는 이름을 사용해서 값을 가져오고 조작할 수 있는 방법입니다. 변수를 효과적으로 사용하면 스크립트가 수행하는 작업을 이해하는 데 도움이 됩니다.

==== 변수 선언

필수 사항은 아니지만, 변수를 사용하기 전에 선언하는 것이 좋은 관행으로 간주됩니다. 변수 선언은 `var` 문을 사용해서 수행합니다. `var` 문을 반드시 사용해야 하는 유일한 경우는 함수 내의 지역 변수를 선언할 때입니다. 지역 변수는 해당 함수 내에서만 유효한 변수를 말합니다. 그 외의 모든 경우는 변수를 사용하기 전에 `var` 문을 사용해서 선언하는 것이 권장되는 관행입니다.

다음은 변수 선언의 예시입니다:

[source,jscript]
----
var mim = “A man, a plan, a canal, Panama!”;  // mim에 저장된 값은 문자열 유형입니다.
// 따옴표로 묶인 문장, 즉 mim에 할당된 값은 문자열 리터럴입니다.

var ror = 3;        // ror에 저장된 값은 숫자형입니다.
var nen = true;        // nen에 저장된 값은 부울형입니다.
var fif = 2.718281828        // fif에 저장된 값은 숫자형입니다.
----


==== 변수 이름 지정

JScript는 “대소문자를 구분” 하는 언어이므로, 변수 이름을 myCounter 로 지정하는 것과 MYCounter 로 지정하는 것은 서로 다릅니다!! 또한, 길이에 제한이 없는 변수 이름은 다음 규칙을 따라야 합니다.

* 첫 번째 문자는 영문자(대문자 또는 소문자), 밑줄(_) 또는 달러 기호($)여야 합니다.
* 그 뒤의 문자는 알파벳, 숫자, 밑줄 또는 달러 기호일 수 있습니다.
* 변수 이름은 예약어일 수 없습니다.

.유효한 변수 이름의 예:
----
_pagecount
Part9
Number_Items
----

.유효하지 않은 변수 이름의 예:
----
99Balloons           // 숫자로 시작합니다.
Smith&Wesson;        // 앰퍼샌드(&)는 변수 이름에 사용할 수 없는 문자입니다.
----

변수를 선언하고 초기화하되, 특정 값을 지정하지 않을 경우는 특수한 값인 `null` 을 할당할 수 있습니다.

[source,jscript]
----
var zaz = null;
var notalot = 3 * zaz;        // 이 시점에서 notalot의 값은 0이 됩니다.
----

변수에 값을 할당하지 않고 선언하면, 그 변수는 존재하지만 정의되지 않은 상태가 됩니다.

[source,jscript]
----
var godot;
var waitingFor = 1 * godot;  // godot이 정의되지 않았기 때문에 waitingFor에 NaN 값이 할당됩니다.
----

값을 할당함으로써 (`var` 를 사용하지 않고) 변수를 “암시적으로 선언” 할 수 있습니다. 그러나 전혀 선언한 적이 없는 변수는 사용할 수 없습니다. 그렇게 하면 런타임에 오류가 발생합니다.

[source,jscript]
----
lel = “”;  // 변수 lel이 암시적으로 선언됩니다.

var aMess = vyv + zez;  // vyv와 zez가 존재하지 않으므로 오류가 발생합니다.
----


==== 강제 형변환

JScript는 느슨한 타입 지정 언어이므로, 기술적으로 JScript의 변수는 고정된 타입을 가지지 않습니다. 대신, 변수는 그 안에 포함된 값의 타입과 동등한 타입을 가집니다. 특정 상황에서 변수나 데이터 조각을 다른 타입으로 자동 변환(강제 형변환)하도록 강제할 수 있습니다. 

숫자는 문자열에 쉽게 포함될 수 있지만, 문자열은 숫자에 직접 포함될 수 없으므로 명시적인 변환 함수인 `parseInt()` 와 `parseFloat()` 가 제공됩니다.

[source,jscript]
----
var theFrom = 1;
var theTo = 10;
var doWhat = “Count from ”;
doWhat += theFrom + “ to ” + theTo + “.”;
----

이 코드가 실행된 후, doWhat 변수는 “Count from 1 to 10.” 이 저장됩니다. 숫자 데이터가 문자열 형태로 강제 변환된 것입니다.

[source,jscript]
----
var nowWhat = 0;
nowWhat += 1 + “10”;  // 이 경우, “10”은 문자열이므로,
                      // “+=” 연산자는 문자열을 연결합니다.
----

위의 코드가 실행된 후, nowWhat 변수는 “0110” 이 저장됩니다. 이 결과에 도달하기까지의 과정은 다음과 같습니다.

* 1 과 “10” 의 데이터형을 살펴봅시다. “10” 은 문자열이고, 1 은 숫자이므로 숫자가 문자열로 변환됩니다.
* + 연산자 양쪽 값 모두 문자열이므로, 문자열 연결 작업이 수행됩니다. 그 결과 “110” 이 됩니다.
* += 연산자 양쪽의 값 유형을 살펴봅니다. nowWhat 은 숫자가 들어 있고, “110” 은 문자열이므로, 숫자를 문자열로 변환합니다.
* 이제 += 연산자 양쪽에 문자열이 있으므로, 문자열 연결 작업이 수행됩니다. 그 결과 “0110” 이 됩니다.
* 이 결과를 nowWhat 변수에 저장합니다.

[source,jscript]
----
var nowThen = 0;
nowThen += 1 + parseInt(“10”);    // 이 경우, “+=” 는 덧셈 연산을 수행합니다.
----

위의 코드가 실행된 후, nowThen 변수는 정수 11 이 저장됩니다.




=== JScript Data Types

JScript의 데이터 유형은 어떤 것들이 있을까요? Microsoft JScript에 따르면 여섯 가지 데이터 유형이 있습니다. 주요 유형은 숫자, 문자열, 객체, 부울형이 있습니다. 나머지 두 가지는 `null` 과 `undefined` 입니다.


==== 문자열 데이터 유형

문자열은 작은따옴표나 큰따옴표로 구분됩니다. (작은 따옴표가 포함된 문자열을 입력할 때는 큰 따옴표를 사용합니다.) 문자열은 JScript에서 객체이기도 하지만, 특별한 속성을 가진 특수한 경우입니다. 다음은 문자열의 예시입니다.

[source,jscript]
----
“The cow jumped over the moon.”
‘“Avast, ye lubbers!” roared the technician.’
“42”
----

문자열은 0개 이상의 유니코드 문자를 포함할 수 있습니다. 문자가 하나도 포함되지 않은 경우, 이를 길이가 0인 문자열(“”)이라고 합니다.


==== 숫자 데이터 유형

JScript는 정수와 부동 소수점 숫자를 모두 지원합니다. 정수는 양수, 0 또는 음수일 수 있으며, 부동 소수점 숫자는 소수점, 과학적 표기법에서 “10의 제곱” 을 나타내는 데 사용되는 “e” (대문자 또는 소문자), 또는 둘 다 포함될 수 있습니다. 이런 숫자는 수치 표현에 관한 IEEE-754 표준을 따릅니다. 마지막으로, 다음과 같은 특수한 숫자 값들이 있습니다:

[source,jscript]
----
NaN(Not a Number)
양의 무한대
음의 무한대
양의 0
음의 0
----

정수는 10진수(십진), 8진수(8진), 16진수(16진)로 표현될 수 있습니다.
    
8진수는 앞쪽에 “0” 이 붙어 표시되며, 0부터 7까지의 숫자로 구성될 수 있습니다. 숫자 앞에 “0” 이 붙어 있지만 “8” 또는 “9” 가 포함된 경우, 이는 10진수입니다. 8진수로 간주되어야 할 숫자에 “e” (또는 “E”) 문자가 포함된 경우 오류가 발생합니다.

16진수(“hex”) 정수는 앞쪽에 “0x” 가 붙어 표기되며(“X” 는 대문자나 소문자 모두 가능), 0부터 9까지의 숫자와 A부터 F까지의 문자(대문자나 소문자 모두 가능)를 포함할 수 있습니다. 문자 “e” 는 16진수 표기법에서 허용되는 숫자이므로, 지수를 나타내는 것이 아닙니다. 문자 A부터 F까지는 10진수에서 10부터 15까지의 숫자를 단일 자릿수로 나타내는 데 사용됩니다. 즉, 0xF 는 15 와 같고, 0x10 은 16 과 같습니다.

8진수와 16진수는 음수일 수 있지만, 소수일 수는 없습니다. 단일 “0” 으로 시작하고 소수점을 포함하는 수는 10진 부동소수점 수입니다. ‘0x’ 또는 “00” 으로 시작하고 소수점을 포함하는 수의 경우, 소수점 오른쪽의 숫자는 무시됩니다.


==== 부울 값

부울 값은 `true` 와 `false` 가 있습니다. 이들은 “특수한 값” 이므로 1 이나 0 으로 사용할 수 없습니다!!

NOTE: 비교 연산에서, 평가 결과가 0 이 되는 모든 식은 `false` 로 간주되며, 0 이 아닌 숫자로 평가되는 모든 식은 `true` 로 간주됩니다. 따라서 다음 식은 `true` 로 평가됩니다: `(false == 0)` 비교 연산에 대한 자세한 내용은 ‘프로그램 흐름 제어’ 섹션을 참조합니다.


==== 정의되지 않은 데이터 유형

“정의되지 않은 값” 이란 변수가 생성된 후, 값이 할당되기 이전의 상태를 말합니다.

==== 연산자 우선순위

JScript의 연산자는 특정 순서에 따라 평가됩니다. 이 순서를 “연산자 우선순위” 라고 합니다. 다음 표는 우선순위가 높은 순서부터 낮은 순서까지 연산자가 나열되어 있습니다. 같은 행에 있는 연산자는 왼쪽에서 오른쪽으로 평가됩니다.

연산자    설명
. [] ()    필드 접근, 배열 인덱싱 및 함수 호출
++ -- - ~ ! typeof new void delete    단항 연산자, 반환 데이터 유형, 객체 생성, 정의되지 않은 값
* / %    곱셈, 나눗셈, 나머지 연산
+ - +    덧셈, 뺄셈, 문자열 연결
<< >> >>>	비트 시프트
< <= > >=    보다 작음, 작거나 같음,보다 큼, 크거나 같음
== != === !==    동일성, 비동일성, 동일, 비동일
&    비트별 AND
^    비트별 XOR

,    중복 평가

괄호는 평가 순서를 변경하는 데 사용됩니다. 괄호 안의 식은 그 값이 문장의 나머지 부분에서 사용되기 전에 완전히 평가됩니다.

우선순위가 높은 연산자는 우선순위가 낮은 연산자보다 먼저 평가됩니다. 예를 들어:

[source,jscript]
----
z = 78 * (96 + 3 + 45)
----

이 식에는 =, *, (), +, + 이렇게 다섯 개의 연산자가 포함되어 있습니다. 연산 우선순위에 따라 이 연산자들은 (), *, +, +, = 순서로 평가됩니다.

먼저 괄호 안의 식을 평가합니다:: 
더하기 연산자가 두 개 있으며, 둘의 우선순위는 동일합니다. 따라서 96 과 3 을 더한 뒤, 그 합에 45 를 더하면 144가 됩니다. 다음으로 곱셈이 수행됩니다. 78 과 144 를 곱하면 11232 가 됩니다. 마지막으로 변수 할당이 수행됩니다. 11232 가 z 변수에 할당됩니다.            
            

=== Controlling Program Flow

왜 실행 흐름을 제어해야 할까요?

상당히 자주, 스크립트가 특정 조건에 따라 서로 다른 작업을 수행할 때가 있습니다. 예를 들어, 매시간 시간을 확인하고 하루 중 상황에 따라 특정 매개변수를 적절하게 변경하는 스크립트를 작성할 수 있습니다. 어떤 종류의 입력을 받아 그에 따라 동작하는 스크립트를 작성할 수도 있습니다. 또는 지정된 작업을 반복하는 스크립트를 작성할 수도 있습니다.

검증할 수 있는 조건은 여러 가지가 있습니다. Microsoft JScript의 모든 조건 검사는 부울(`Boolean`) 형식이므로, 검사 결과는 참(`true`) 또는 거짓(`false`) 중 하나입니다. 부울, 숫자 또는 문자열 유형의 값을 자유롭게 검사할 수 있습니다.

JScript는 다양한 가능성에 대비한 제어 구조를 제공합니다. 가장 간단한 제어 구조는 조건문입니다.
    
==== 조건문 사용

JScript는 `if` 및 `if...else` 조건문을 지원합니다. `if` 문에서 조건이 검사되며, 조건이 충족되면 작성한 JScript 코드가 실행됩니다. (`if...else` 문은 조건이 충족되지 않을 경우 다른 코드가 실행됩니다.) `if` 문은 가장 간단한 형태로 한 줄에 모두 작성할 수 있지만, 여러 줄에 걸친 `if` 및 `if...else` 문이 훨씬 더 일반적입니다.

다음 예제는 `if` 및 `if...else` 문에서 사용할 수 있는 구문을 보여줍니다. 첫 번째 예제는 가장 간단한 형태의 부울 조건 검사를 보여줍니다. 괄호 안의 항목이 `true` 로 평가될 경우(그리고 오직 그 경우만), `if` 뒤의 문 또는 문 블록이 실행됩니다.

[source,jscript]
----
// smash() 함수는 코드의 다른 곳에서 정의되어 있습니다.
if (newShip)
   smash(champagneBottle, bow);  // newShip 이 참인지 여부에 대한 부울 조건 검사.

// 이 예제는 두 조건이 모두 참일 때만 테스트가 성공합니다.
if (rind.color == “deep yellow ” && rind.texture == “large and small wrinkles”)
{
        theResponse = (“Is it a Crenshaw melon? <br> ”);
}

// 이 예제는 두 조건 중 하나라도 참이면 테스트가 성공합니다.
var theReaction = “”;
if ((lbsWeight > 15) || (lbsWeight > 45))
{
    theReaction = (“오, 정말 귀여운 고양이네요! <br>”);
}
else
    theReaction = (“와, 정말 거대한 고양이네요! <br>”);
----


==== 조건 연산자

JScript는 암시적 조건문 형식도 지원합니다. 이 형식은 테스트할 조건 뒤에 물음표(조건 앞에 ‘if’ 라는 단어를 사용하는 대신)를 사용하고, 조건이 충족될 때와 충족되지 않을 때 각각 적용될 두 가지 대안을 지정합니다. 두 대안은 콜론으로 구분됩니다.

[source,jscript]
----
 var hours = “”;

 // hours 에 theHour 의 값이 포함되거나,
 // theHour - 12 가 포함되도록 지정하는 코드.

 hours += (theHour >= 12) ? “ PM” : “ AM”;
----

TIP: 함께 테스트할 조건이 여러 개 있고, 테스트가 OR (`||`) 또는 AND (`&&`) 논리 연산자로 연결된지에 따라 특정 조건이 다른 조건들보다 통과하거나 실패할 가능성이 더 높다는 것을 알고 있다면, 해당 조건을 조건문 맨 앞에 배치해서 스크립트의 실행 속도를 높일 수 있습니다. 예를 들어, 세 가지 조건이 모두 참이어야 하는 경우(`&&` 연산자 사용) 두 번째 테스트가 실패하면 세 번째 조건은 테스트되지 않습니다.

마찬가지로, 여러 조건 중 하나만 참이어야 하는 경우(`||` 연산자 사용), 조건 중 하나라도 통과하면 테스트가 즉시 중단됩니다. 이는 테스트할 조건에 함수 호출이나 기타 실행 코드가 포함된 경우 특히 효과적입니다.

단락 평가의 부작용 예로, 다음 예제에서 runfirst() 함수가 0 또는 `false` 를 반환하면 runsecond() 함수는 실행되지 않습니다.

[source,jscript]
----
if ((runfirst() == 0) || (runsecond() == 0))
// 일부 코드
----


==== 반복(루프) 사용

문이나 문 블록을 반복 실행하는 방법은 여러 가지가 있습니다. 일반적으로 이런 반복적인 실행을 ‘루프’ (_Loop_)라고 합니다. 루프는 대개 어떤 변수에 대한 조건 검사에 의해 제어되며, 이 변수의 값은 루프가 실행될 때마다 변경됩니다. Microsoft JScript는 `for` 루프, `for...in` 루프, `while` 루프, `do...while` 루프, `switch` 루프 등 다양한 유형의 루프를 지원합니다.

===== for 루프 사용

`for` 문은 카운터 변수, 테스트 조건, 그리고 카운터를 업데이트하는 동작을 지정합니다. 루프가 실행되기 직전(이를 루프의 “한 번의 통과” 또는 “한 번의 반복” 이라고 합니다)에 조건이 테스트됩니다. 루프가 실행된 후, 다음 반복이 시작되기 전에 카운터 변수가 업데이트됩니다.

루프 실행 조건이 한 번도 충족되지 않으면 루프는 전혀 실행되지 않습니다. 반면, 조건이 항상 충족되면 무한 루프가 발생합니다. 전자의 경우는 특정 상황에서 바람직할 수 있지만, 후자의 경우는 대부분의 경우 바람직하지 않으므로 루프 조건을 작성할 때는 주의해야 합니다.

[source,jscript]
----
/*
업데이트 표현식(다음 예제에서 “icount++”)은
루프 본문을 구성하는 문 블록이 실행된 후, 조건이 검사되기 전에
루프의 마지막에서 실행됩니다.
*/

var howFar = 11;              // 루프의 상한을 11로 설정합니다.

var sum = new Array(howFar);  // 0부터 10까지 11개의 요소를 가진 sum 이라는 배열을 생성합니다.
var theSum = 0;
sum[0] = 0;

for(var icount = 1; icount < howFar; icount++)  {        // 이 경우 1부터 10까지 카운트합니다.
theSum += icount;
sum[icount] = theSum;
}

var newSum = 0;
for(var icount = 1; icount > howFar; icount++)  {        // 이 코드는 전혀 실행되지 않습니다.
newSum += icount;
}

var sum = 0;
for(var icount = 1; icount > 0; icount++)  {             // 이것은 무한 루프입니다.
sum += icount;
}
----


===== for...in 루프 사용하기

JScript는 객체의 모든 속성을 순차적으로 처리하기 위한 특수한 종류의 루프를 제공합니다. `for...in` 루프의 루프 카운터는 배열의 모든 인덱스를 순차적으로 처리합니다. 이 카운터는 숫자가 아닌 문자열입니다.

[source,jscript]
----
for (j in tagliatelleVerde)  // tagliatelleVerde 는 여러 속성을 가진 객체입니다
{
// 다양한 JScript 코드 문장들...
}
----


===== while 루프 사용하기

`while` 루프는 `for` 루프와 매우 유사합니다. 차이점은 `while` 루프는 “내장된 카운터 변수나 업데이트 표현식이 없다” 는 점입니다. 이미 변수에 할당된 값에 반영되는 변화하는 조건이 있고, 이를 사용해서 문이나 문 블록의 반복 실행을 제어하려면 `while` 루프를 사용합니다.

[source,jscript]
----
var theMoments = “”;
var theCount = 42;        // 카운터 변수를 초기화합니다.
while (theCount >= 1)  {
    if (theCount > 1)  {
        theMoments = “남은 순간은 ” + theCount + “개 뿐입니다!”;
}
    else  {
        theMoments = “남은 순간은 단 하나 뿐입니다!”;
    }
theCount--;               // 카운터 변수를 업데이트합니다.
}
theMoments = “발사!”;
----

NOTE: `while` 루프는 명시적인 내장 카운터 변수가 없기 때문에, 다른 유형의 루프보다 무한 루프에 훨씬 더 취약합니다. 게다가 루프 조건이 어디서, 언제 업데이트되는지 파악하기가 반드시 쉬운 것은 아니기 때문에, 실제로 조건이 전혀 업데이트되지 않는 `while` 루프를 작성하기가 너무 쉽습니다. `while` 루프를 설계할 때는 각별히 주의해야 합니다.


===== break 및 continue 문 사용

Microsoft JScript는 루프 실행을 중지하는 문을 제공합니다. `break` 문은 특정(대개 특수한) 조건이 충족될 때 실행을 중지하는 데 사용할 수 있습니다. `continue` 문은 `for` 또는 `for...in` 루프인 경우, 코드 블록의 나머지 부분을 “건너뛰고” 카운터 변수는 평소와 같이 업데이트한 채로 즉시 다음 반복으로 이동하는 데 사용할 수 있습니다.

[source,jscript]
----
var theComment = “”;
var theRemainder = 0;
var theEscape = 3;
var checkMe = 27;
for (kcount = 1; kcount <= 10; kcount++)
{
    theRemainder = checkMe % kcount;

}
theComment = checkMe + “를 ” + kcount + “로 나누면 나머지는 ” + theRemainder;
}

for (kcount = 1; kcount <= 10; kcount++)
{
   theRemainder = checkMe % kcount;
   if (theRemainder != theEscape)

   {
      continue;      // 'theEscape' 같은 나머지만 선택하고, 나머지는 모두 무시합니다.
}
// 선택된 나머지 값을 사용하는 JScript 코드...
}

var theMoments = “”;
var theCount = 42;        // 카운터가 초기화됩니다.
while (theCount >= 1)  {
// if (theCount < 10)  {  // 경고!
// 이렇게 continue 를 사용하면 무한 루프가 발생합니다!
// continue;
// }
    if (theCount > 1)  {
        theMoments = “남은 순간은 ” + theCount + “개 뿐입니다!”;
}
    else  {
        theMoments = “남은 순간은 단 하나 뿐입니다!”;
    }
theCount--;              // 카운터가 업데이트됩니다.
}
theCount = “발사!”;
----



=== JScript Functions

==== 함수란 무엇인가?

Microsoft JScript 함수는 특정 작업을 수행합니다. 또한 결과를 반환할 수도 있습니다. 때로는 이런 결과가 계산이나 비교 연산의 결과일 수도 있습니다.

함수는 여러 연산을 하나의 이름으로 묶어줍니다. 이를 통해 코드를 간소화할 수 있습니다. 일련의 문장을 작성하고 이름을 지정한 다음, 필요할 때마다 해당 함수를 호출하고 필요한 정보를 전달하면 전체 문장 집합을 실행할 수 있습니다.

함수에 정보를 전달하려면 함수 이름 뒤에 괄호를 사용해서 정보를 포함시키면 됩니다. 함수에 전달되는 정보를 “인자” 또는 “매개변수” 라고 합니다. 어떤 함수는 인자를 전혀 받지 않고, 어떤 함수는 인자를 하나만 받으며, 어떤 함수는 여러 개를 받기도 합니다. 심지어 함수를 사용하는 방법에 따라 인자의 수가 달라지는 함수도 있습니다.

JScript는 언어에 내장된 함수와 사용자가 직접 만드는 함수, 두 가지 종류의 함수를 지원합니다.

===== 특수 내장 함수

JScript 언어는 여러 개의 내장 함수가 포함되어 있습니다. 그중 일부는 표현식과 특수 문자를 처리하거나, 문자열을 숫자 값으로 변환하는 데 사용됩니다.

예를 들어, escape() 와 unescape() 함수는 HTML 코드에서 특별한 의미를 가지며 텍스트에 직접 넣을 수 없는 문자를 변환하는 데 사용됩니다. 각괄호인 “<” 와 “>” 문자는 HTML 태그를 구분하는 역할을 합니다.

escape() 함수는 이런 특수 문자 중 하나를 인수로 받아 해당 문자의 이스케이프 코드를 반환합니다. 각 이스케이프 코드는 퍼센트 기호(%) 뒤에 두 자리 숫자가 붙은 형태로 구성됩니다. unescape() 함수는 이와 정확히 반대되는 역할을 처리합니다. 이 함수는 퍼센트 기호와 두 자리 숫자로 구성된 문자열을 인수로 받아 문자를 반환합니다.

또 다른 유용한 내장 함수는 eval() 로, 문자열 형태로 주어진 유효한 수학 식을 평가합니다. eval() 함수는 평가할 식을 하나의 인자로 받습니다.

[source,jscript]
----
var anExpression = “6 * 9 % 7”;
var total = eval(anExpression);        // 변수 total에 값 5를 할당합니다.
var yetAnotherExpression = “6 * (9 % 7)”;
total = eval(yetAnotherExpression)        // 변수 total에 값 12를 할당합니다.

var totality = eval(“...surrounded by acres of clams.”);        // 오류가 발생합니다.
----

이런 함수 및 기타 내장 함수에 대한 자세한 내용은 언어 참조 문서를 참조합니다.


===== 사용자 정의 함수 만들기

사용자 정의 함수를 만들어 필요한 곳에서 사용할 수 있습니다. 함수 정의는 함수 문과 JScript 문 블록으로 구성됩니다.    

다음 예제의 checkTriplet() 함수는 삼각형의 변의 길이를 인수로 받아, 이 세 수가 피타고라스 삼중항을 이루는지 확인해서 해당 삼각형이 직각삼각형인지 여부를 계산합니다. (직각삼각형의 빗변 길이의 제곱은 나머지 두 변의 길이의 제곱의 합과 같습니다.) checkTriplet() 함수는 실제 검증을 수행하기 위해 다른 두 함수 중 하나를 호출합니다.

부동소수점 버전의 검증에서 매우 작은 수(“epsilon”)가 검증 변수로 사용된 점에 유의합니다. 부동소수점 계산의 불확실성과 반올림 오차로 인해, 해당 세 값이 모두 정수임이 확실치 않은 한, 빗변의 제곱이 나머지 두 변의 제곱의 합과 같은지 직접 테스트하는 것은 실용적이지 않습니다. 직접 테스트가 좀 더 정확하기 때문에, 이 예제의 코드는 직접 테스트가 적절한지 판단하고, 적절한 경우 이를 사용합니다.

[source,jscript]
----
var epsilon = 0.0000000000001;          // 테스트에 사용할 매우 작은 수.
var triplet = false;

function integerCheck(a, b, c)  {       // 정수 여부를 확인하는 테스트 함수.
    if ( (a*a) == ((b*b) + (c*c)) )  {  // 실제 테스트 코드.
    triplet = true;
    }
}                                       // 정수 확인 함수 끝.

function floatCheck(a, b, c)  {         // 부동소수점 숫자에 대한 테스트 함수.
var theCheck = ((a*a) - ((b*b) + (c*c)))  // 테스트 숫자를 생성합니다.
    if (theCheck < 0)  {                // 테스트는 절댓값이 필요하므로, theCheck 가 음수일 경우 부호를 반전시킵니다.
    theCheck *= -1;
    }
    if (epsilon > theCheck)  {          // 그 정도까지 가까우면 정말 아주 근접한 것입니다!
    triplet = true;
    }
}                                       // 부동소수점 검사 함수 끝.

function checkTriplet(a, b, c)  {       // 삼각형 검사 함수. 먼저, 가장 긴 변을 “a” 위치로 이동시킵니다.
var d = 0;                              // 임시 저장 변수를 생성합니다.
    if (c > b)  {                       // c > b인 경우, 두 변을 서로 바꿉니다.
    d = c;
    c = b;
    b = d;
    }                                   // 그렇지 않다면 무시합니다.
    if (b > a)  {                       // b가 a보다 크면, 둘을 바꿉니다.
    d = b;
    b = a;
    a = d;
    }                                   // 그렇지 않다면 무시합니다.

// 이제 변 “a” 는 빗변이 됩니다(빗변이 존재하는 경우).

    if (((a%1) == 0) && ((b%1) == 0) && ((c%1) == 0))  {  // 3개의 값을 모두 검사합니다. 정수인가요?
    integerCheck(a, b, c);                                // 그렇다면 정확한 검사를 수행합니다.
    }
    else
        floatCheck(a, b, c);                              // 그렇지 않다면, 합리적으로 가능한 한 근사치를 구합니다.
}                                       // 3원조 검사 함수 끝.

// 다음 세 문장은 테스트를 위해 예시 값을 할당합니다.
var sideA = 5;
var sideB = 5;
var sideC = Math.sqrt(50);

checkTriplet(sideA, sideB, sideC);      // 함수를 호출합니다. 호출 후, triplet에는 결과가 저장됩니다.
----



=== JScript Objects

==== 객체란 무엇인가?

Microsoft JScript에서 객체는 본질적으로 “속성과 메서드의 모음” 입니다. 메서드는 객체의 구성원인 함수이며, 속성은 객체의 구성원인 값 또는 값의 집합(배열이나 객체 형태)입니다. JScript는 내장 객체, 사용자가 생성한 객체, 그리고 다른 곳에서 다루는 브라우저 객체 등 세 가지 종류의 객체를 지원합니다.


===== 배열로서의 객체

JScript는 객체와 배열이 동일하게 처리됩니다. 객체의 구성 요소(속성 및 메서드)는 이름(객체 이름 뒤에 마침표, 그 뒤에 속성 이름을 붙이는 방식)이나 배열 인덱스를 사용해서 참조할 수 있습니다. JScript에서 인덱스 번호는 0부터 시작합니다. 편의를 위해 인덱스를 이름으로 참조할 수도 있습니다.

따라서 속성은 여러 가지 방법으로 참조할 수 있습니다. 다음 문장들은 모두 동일합니다.

[source,jscript]
----
theWidth = spaghetti.width;
theWidth = spaghetti[3];               // [3]은 “width”의 인덱스입니다.
theWidth = spaghetti[“width”];
----

대괄호를 사용해서 숫자 인덱스로 속성에 접근하는 것도 가능하지만, 인덱스 번호에 점(`.`) 표기법을 사용하는 것은 불가능합니다. 다음 문장은 오류를 발생시킵니다.

[source,jscript]
----
theWidth = spaghetti.3;
----

객체가 다른 객체를 속성으로 가질 때, 명명 규칙은 직관적인 방식으로 확장됩니다.

[source,jscript]
----
var init4 = toDoToday.shoppingList[3].substring(0,1);  // shoppingList는 toDoToday의 속성인 배열입니다.
----

“객체가 다른 객체를 속성으로 가질 수 있다” 는 사실 덕분에, 직접 지원되지 않는 여러 인덱스를 가진 배열을 생성할 수 있습니다. 다음 코드는 0 × 0부터 16 × 16까지의 곱셈표를 생성합니다.

[source,jscript]
----
var multTable = new Array(17);                  // 곱셈표가 될 뼈대를 만듭니다.
for (var j = 0; j < multTable.length; j++)  {   // 행을 채울 준비를 합니다.
    var aRow = new Array(17);  // 행을 생성합니다.
    for (var i = 0; i < aRow.length; i++)  {    // 행을 채울 준비를 합니다.
    aRow[i] = (i + “ × ” + j + “ = ” + i*j);    // 하나의 값을 생성하여 배치합니다.
    }
multTable[j] = aRow;                            // 채워진 행을 테이블에 넣습니다.
}
----

이런 종류의 배열 요소 중 하나를 참조하려면 중첩된 대괄호를 사용해야 합니다.

[source,jscript]
----
var multiply3x7 = multTable[3][7];
----

다음 문장은 오류를 발생시킵니다.

[source,jscript]
----
var multiply3x7 = multTable[3, 7];
----



=== JScript Reserved Keywords

JScript는 여러 가지 예약어(_keyword_)가 있습니다. 이 단어는 JScript 예약어, 향후 예약어, 사용을 피해야 할 단어의 세 가지 유형으로 나뉩니다.

.JScript 예약어
break    false    in    this    void
continue    for    new    true    while
delete    function    null    typeof    with
else    if    return    var


.JScript 향후 키워드
case    debugger    export    super
catch    default    extends    switch
class    do    finally    throw
const    enum    import    try

피해야 할 단어는 이미 JScript의 내장 객체나 함수 이름으로 사용되는 모든 단어입니다. `String` 이나 `parseInt` 같은 단어도 여기에 포함됩니다.

첫 번째와 두 번째 범주에 속하는 키워드를 사용하면 스크립트가 처음 로드될 때 컴파일 오류가 발생합니다. 세 번째 범주에 속하는 예약어를 사용할 경우, 동일한 스크립트 내에서 사용자 정의 변수와 동일한 이름을 가진 원래 객체를 동시에 사용하려고 하면 예기치 않은 동작 문제가 발생할 수 있습니다. 예를 들어, 다음 스크립트는 사용자가 예상한 대로 작동하지 않습니다:

[source,jscript]
----
var String;
var text = new String(“This is a string object”);
----

이 경우, `String` 이 객체가 아니라는 오류 메시지가 표시됩니다. 기존 식별자를 사용하는 많은 사례는 이처럼 명백하지 않습니다.



== Advanced JScript

=== Recursion

재귀는 중요한 프로그래밍 기법입니다. 이는 함수가 그 내부에서 스스로를 호출하도록 하는 데 사용됩니다. 유용한 예로 팩토리얼 계산이 있습니다. 0과 1의 팩토리얼은 모두 1로 명시적으로 정의되어 있습니다. 더 큰 숫자의 팩토리얼은 1 × 2 × …를 곱하는 방식으로 계산되며, 팩토리얼을 구하려는 숫자에 도달할 때까지 1씩 증가시킵니다.

다음 문단은 팩토리얼을 계산하는 함수를 문장으로 정의한 것입니다.

“숫자가 0보다 작으면 거부합니다. 정수가 아니면 다음 정수로 반올림합니다. 숫자가 0이나 1이면 그 팩토리얼은 1입니다. 숫자가 1보다 크면, 그 숫자보다 한 단계 작은 숫자의 팩토리얼과 곱합니다.”

1보다 큰 어떤 수의 계승을 계산하려면, 적어도 하나의 다른 수의 계승을 계산해야 합니다. 이를 위해 사용하는 함수는 이미 작성 중인 이 함수 그 자체입니다. 이 함수는 현재 수에 대한 연산을 수행하기 전에, 바로 다음으로 작은 수에 대해 스스로를 호출해야 합니다. 이것이 재귀의 한 예입니다.

[source,jscript]
----
function factorial(aNumber)  {
aNumber = Math.floor(aNumber);  // 숫자가 정수가 아닐 경우, 아래로 반올림합니다.
if (aNumber < 0)  {  // 숫자가 0보다 작을 경우, 처리를 거부합니다.
    return “정의되지 않은 수”;
    }
      if ((anumber == 0) || (anumber == 1))  {  // 숫자가 0이거나 1인 경우, 그 계승은 1입니다.
      return 1;
      }
        else return (anumber * factorial(anumber - 1));  // 그렇지 않은 경우, 완료될 때까지 재귀를 수행합니다.
}
----

분명히 여기서 문제가 발생할 여지가 있습니다. 결코 명확한 결과를 얻지 못하고 종료점에 도달할 수 없는 재귀 함수를 쉽게 만들 수 있습니다. 이런 재귀는 컴퓨터가 소위 “무한” 루프를 실행하도록 만듭니다. 예를 들겠습니다. 팩토리얼 계산에 대한 설명에서 첫 번째 규칙(음수에 관한 규칙)을 생략하고, 임의의 음수의 팩토리얼을 계산해 보세요. 이 방법은 실패합니다! 왜냐하면, -24의 계승값을 계산하려면 먼저 -25의 계승값을 계산해야 하고, 이를 위해서는 다시 -26의 계승값을 계산해야 하며, 이런 과정이 계속 반복되기 때문입니다. 분명, 이 과정은 결코 멈출 지점에 도달하지 못합니다.

따라서 재귀 함수를 설계할 때는 각별한 주의를 기울이는 것이 매우 중요합니다. 무한 재귀가 발생할 가능성이 조금이라도 있다고 의심된다면, 함수가 자신을 호출한 횟수를 세도록 처리할 수 있습니다. 함수가 자신을 정해진 횟수(사용자가 정한 횟수)보다 더 많이 호출하면 자동으로 종료됩니다.

다음은 다시 한 번 팩토리얼 함수입니다. 이번에는 JScript 코드로 작성되었습니다.

[source,jscript]
----
function factorial(aNumber)  {
aNumber = Math.floor(aNumber);       // 숫자가 정수가 아닐 경우, 아래로 반올림합니다.

    return “정의되지 않은 수”;
    }

      return 1;
      }

----



=== Variable Scope

 Microsoft JScript는 전역(_global_)과 지역(_local_) 두 가지 범위가 있습니다. 함수 정의 외부에서 변수를 선언하면 해당 변수는 전역 변수가 되며, 프로그램 전체에서 그 값에 접근하고 수정할 수 있습니다. 함수 정의 내부에서 변수를 선언하면 해당 변수는 지역 변수가 됩니다. 이 변수는 함수가 실행될 때마다 생성되고 소멸되며, 함수 외부에서는 어떤 방식으로도 접근할 수 없습니다.

로컬 변수는 전역 변수와 같은 이름을 가질 수 있지만, 완전히 별개의 독립된 변수입니다. 따라서 한 변수의 값을 변경해도 다른 변수에 아무런 영향도 미치지 않습니다. 로컬 변수가 선언된 함수 내부에서는 로컬 변수만 유효합니다.

[source,jscript]

=== Copying, Passing, and Comparing Data



    Microsoft JScript에서 데이터의 처리 방식은 데이터 유형에 따라 달라집니다.

값 전달 대 참조 전달

    숫자와 부울 값(true 및 false)은 값으로 복사, 전달 및 비교됩니다. 값으로 복사하거나 전달할 때는 컴퓨터 메모리에 공간을 할당하고 원본의 값을 그 공간에 넣습니다. 이후 원본을 변경하더라도 복사본에는 영향을 미치지 않습니다(반대의 경우도 마찬가지입니다). 이는 둘이 별개의 개체이기 때문입니다.

    객체, 배열 및 함수는 대부분의 경우 참조 방식으로 복사, 전달 및 비교됩니다. 참조 방식으로 복사하거나 전달할 때는 본질적으로 원본 항목에 대한 포인터를 생성하고, 이 포인터를 마치 복사본인 것처럼 사용합니다. 이후 원본을 변경하면 원본과 복사본 모두 변경됩니다(반대의 경우도 마찬가지입니다). 실제로는 하나의 개체만 존재하며, “복사본”은 실제 복사본이 아니라 데이터에 대한 또 다른 참조일 뿐입니다.

    참고  객체와 배열의 경우 assign( ) 메서드를 지정하여 이 동작을 변경할 수 있습니다.

    마지막으로, 문자열은 복사 및 참조 전달되지만, 값 비교는 값 단위로 이루어집니다.

    참고  ASCII 및 ANSI 문자 집합의 구성 방식 때문에, 대문자는 소문자보다 순서상 먼저 옵니다. 예를 들어, “Zoo”는 “aardvark”보다 작게 비교됩니다.

함수에 매개변수 전달하기

    매개변수를 값으로 함수에 전달하면, 해당 매개변수의 별도 사본이 생성되며, 이 사본은 함수 내부에서만 존재합니다. 반면, 매개변수를 참조로 전달하고 함수 내에서 해당 매개변수의 값을 변경하면, 스크립트 전체에서 해당 값이 변경됩니다.

데이터 비교

    값 비교를 수행할 때는 서로 다른 두 항목을 비교하여 서로 동일한지 확인합니다. 일반적으로 이 비교는 바이트 단위로 수행됩니다. 참조 비교를 수행할 때는 두 항목이 하나의 원본 항목을 가리키는 포인터인지 확인합니다. 그렇다면 두 항목은 동일한 것으로 비교되지만, 그렇지 않다면 바이트 단위로 정확히 동일한 값을 포함하고 있더라도 서로 다른 것으로 비교됩니다.

    문자열을 복사하거나 참조로 전달하면 메모리를 절약할 수 있습니다. 하지만 문자열은 일단 생성되면 변경할 수 없기 때문에, 값으로 비교하는 것이 가능해집니다. 이를 통해 두 문자열이 서로 완전히 별도로 생성된 경우라도 동일한 내용을 가지고 있는지 확인할 수 있습니다.


=== Using Arrays

배열 인덱싱

    JScript의 배열은 스파스(sparse)합니다. 즉, 0, 1, 2로 번호가 매겨진 세 개의 요소를 가진 배열이 있다면, 3번부터 49번까지의 요소에 대해 신경 쓰지 않고도 50번 요소를 생성할 수 있습니다. 배열에 자동 길이 변수가 있는 경우(배열 길이의 자동 모니터링에 대한 설명은 ‘내장 객체’ 항목 참조), 길이 변수는 4가 아닌 51로 설정됩니다. 물론 요소 번호에 공백이 없는 배열을 생성할 수도 있지만, 반드시 그래야 하는 것은 아닙니다. 사실 JScript에서는 배열에 번호가 매겨진 인덱스가 전혀 없을 수도 있습니다.

    JScript에서 객체와 배열은 본질적으로 서로 동일합니다. 실제 차이점은 데이터에 있는 것이 아니라, 배열의 구성원이나 객체의 속성 및 메서드에 접근하는 방식에 있습니다.

배열 참조하기

    배열의 구성 요소에 접근하는 데는 크게 두 가지 방법이 있습니다. 일반적으로 대괄호를 사용하여 배열에 접근합니다. 대괄호 안에는 숫자 값이나 음이 아닌 정수로 평가되는 식이 들어갑니다. 다음 예제는 entryNum 변수가 스크립트의 다른 곳에서 정의되고 값이 할당되었다고 가정합니다.

        theFirstLine = theListing[1];

    이러한 참조 방법은 객체를 참조하는 방법과 동일하지만, 객체 참조의 경우 점(.) 뒤에 실제 속성의 이름이 와야 합니다. 해당 속성이 없으면 코드에서 오류가 발생합니다.

 배열에 접근하는 두 번째 방법은 번호가 매겨진 속성을 포함하는 객체/배열을 만든 다음, 루프를 통해 번호를 생성하는 것입니다. 다음 예제는 addressBook에 있는 목록을 바탕으로 이름용과 주소용 배열 두 개를 생성합니다. 이 배열들은 각각 네 개의 속성을 포함합니다. 예를 들어, theListing의 [Name1]부터 [Name4] 속성을 기반으로 생성된 theName 인스턴스에는 “G.”, “Edward”, “Heatherington”, “IV” 또는 “George”, “”, ‘Sand’, “”와 같은 값이 포함될 수 있습니다.

    theListing = addressBook[entryNum];
    for (i = 1; i < 4; i++)  {
    theName[i] = theListing[“Name” + i];
    theAddress[i] = theListing[“Address” + i];

이 특정 예제는 짧고, “점(.)” 표기법(즉, theListing, theName, theAddress를 배열이 아닌 객체로 다루는 방식)으로 쉽게 작성할 수도 있었겠지만, 항상 그런 방식이 가능한 것은 아닙니다. 때로는 특정 속성이 실행 시점이 되어서야 존재하거나, 사전에 어떤 속성일지 알 수 없는 경우도 있습니다. 예를 들어, addressBook 배열이 번호순 목록이 아닌 성순으로 정렬되어 있다면, 사용자는 스크립트가 실행되는 동안 사람을 찾기 위해 이름을 “즉석에서” 입력하게 될 것입니다. 다음 예제는 스크립트의 다른 곳에 적절한 함수 정의가 존재한다고 가정합니다.

다음 코드는 가장 익숙한 형태의 배열을 생성하고 초기화합니다.

이 배열에서는 배열 요소 번호(0, 1, 2) 대신 키 문자열(“a”, ‘b’ 또는 “c”)을 사용하여 요소에 접근합니다. 이를 통해 보다 직관적인 주소 지정 방식을 가진 배열을 생성하고 사용할 수 있습니다. 위에서 보여준 for...in 문 코드도 이 배열을 반복하는 데 사용할 수 있습니다.

=== Special Characters

특수 문자

    JScript는 직접 입력할 수 없는 일부 문자를 문자열에 포함할 수 있게 해주는 특수 문자를 제공합니다. 이러한 각 문자는 백슬래시로 시작합니다. 백슬래시는 JScript 인터프리터에 다음 문자가 특수 문자임을 알리기 위해 사용하는 이스케이프 문자입니다.

    이스케이프 시퀀스    문자
    \b    백스페이스
    \f    폼 피드
    \n	줄 바꿈(새 줄)
    \r    캐리지 리턴
    \t    수평 탭 (Ctrl-I)
    \'    작은 따옴표
    \"    큰 따옴표
    \\    백슬래시

    백슬래시 자체가 이스케이프 문자로 사용되므로, 스크립트에서 백슬래시를 직접 입력할 수 없다는 점에 유의하십시오. 백슬래시를 입력하려면 두 개를 연속해서 입력해야 합니다 (\\).

        document.write(‘이미지 경로는 C:\\webstuff\\mypage\\gifs\\garden.gif입니다.’);
        document.write(‘캡션은 “97년 눈이 내린 후. 할머니 댁이 눈으로 덮여 있습니다.”라고 적혀 있습니다.’);

    이러한 이스케이프 시퀀스를 사용하면 <PRE> 및 <XMP> 태그 내부의 텍스트 서식을 제어할 수 있으며, 어느 정도는 alert, prompt, confirm 메시지 상자 내부의 서식도 제어할 수 있습니다.



=== Troubleshooting Your Scripts

     어떤 프로그래밍 언어든 주의하지 않으면 실수를 하기 쉬운 부분이 있으며, 모든 언어에는 그 언어만의 특이한 점이 있습니다. 예를 들어, null 값을 생각해 보세요. Microsoft JScript의 null 값은 C나 C++ 언어의 null 값과는 다르게 동작합니다.

    다음은 JScript 스크립트를 작성할 때 마주칠 수 있는 몇 가지 문제점입니다.

구문 오류

    프로그래밍 언어의 구문은 자연어보다 훨씬 엄격하기 때문에, 스크립트를 작성할 때는 세부 사항에 세심한 주의를 기울이는 것이 중요합니다. 예를 들어, 특정 매개변수를 문자열로 지정하려는 경우, 입력할 때 따옴표로 묶는 것을 잊으면 문제가 발생합니다.

스크립트 해석 순서

    JScript 해석은 웹 브라우저의 HTML 구문 분석 과정의 일부입니다. 따라서 문서 내 <HEAD> 태그 안에 스크립트를 배치하면, <BODY> 태그가 분석되기 전에 해당 스크립트가 해석됩니다. <BODY> 태그 내에서 생성된 객체가 있다면, <HEAD>이 구문 분석될 당시에는 해당 객체가 존재하지 않으므로 스크립트를 통해 조작할 수 없습니다.

자동 형 변환

    JScript는 자동 형 변환 기능을 갖춘 느슨한 형 지정 언어입니다. 따라서 서로 다른 형의 값은 서로 같지 않음에도 불구하고, 다음 예제의 표현식은 true로 평가됩니다.

        “100” == 100
        false == 0

연산자 우선순위

    표현식을 평가하는 과정에서 특정 연산이 언제 수행되는지는 표현식 내에서의 위치보다는 연산자 우선순위에 더 크게 좌우됩니다. 따라서 다음 예제에서, 뺄셈이 표현식에서 먼저 나타나더라도 곱셈이 뺄셈보다 먼저 수행됩니다.

        theRadius = aPerimeterPoint - theCenterpoint * theCorrectionFactor;

객체와 함께 for...in 루프 사용하기

    for...in 루프를 사용하여 객체의 속성을 순차적으로 처리할 때, 객체의 필드가 루프 카운터 변수에 할당되는 순서를 반드시 예측하거나 제어할 수 있는 것은 아닙니다. 게다가 언어의 구현 방식에 따라 순서가 다를 수도 있습니다.

with 키워드

    with 문은 지정된 객체에 이미 존재하는 속성을 처리하는 데 편리하지만, 객체에 속성을 추가하는 데는 사용할 수 없습니다. 객체에 새로운 속성을 생성하려면 해당 객체를 명시적으로 참조해야 합니다.

this 키워드

     객체 정의 내부에서는 객체 자체를 가리키기 위해 `this` 키워드를 사용하지만, 일반적으로 함수가 객체 정의가 아닐 때는 `this`나 이와 유사한 키워드를 사용하여 현재 실행 중인 함수를 가리킬 수 없습니다. 단, 해당 함수가 메서드로 객체에 할당될 예정인 경우에는 함수 내에서 `this` 키워드를 사용하여 객체를 가리킬 수 있습니다.

스크립트를 작성하는 스크립트

    인터프리터가 </SCRIPT> 태그를 발견하면 현재 스크립트를 종료합니다. “</SCRIPT>” 자체를 표시하려면, 이를 “</SCR”과 “IPT>”와 같이 최소 두 개의 문자열로 다시 작성한 다음, 이를 출력하는 문장에서 두 문자열을 연결하면 됩니다.

암시적 창 참조

    한 번에 여러 개의 창이 열려 있을 수 있으므로, 암시적인 창 참조는 모두 현재 창을 가리키는 것으로 간주됩니다. 다른 창을 참조하려면 명시적인 참조를 사용해야 합니다.   





== Using JScript In Internet Explorer



=== Displaying Information in the Browser

     Microsoft JScript는 브라우저에서 데이터를 직접 표시하는 두 가지 방법을 제공합니다. document 객체의 메서드인 write( )와 writeln( )을 사용할 수 있습니다. 또한 브라우저 내의 양식이나 alert, prompt, confirm 메시지 상자에 정보를 표시할 수도 있습니다.

document.write( ) 및 document.writeln( ) 사용

    정보를 표시하는 가장 일반적인 방법은 document 객체의 write( ) 메서드를 사용하는 것입니다. 이 메서드는 하나의 인자(문자열)를 받아 브라우저에 표시합니다. 이 문자열은 일반 텍스트이거나 HTML일 수 있습니다.

    문자열은 작은따옴표나 큰따옴표로 묶을 수 있습니다. 이를 통해 따옴표나 아포스트로피가 포함된 내용을 인용할 수 있습니다.

        document.write(“Pi는 대략 ” + Math.PI);
        document.write( );

팁  다음과 같은 간단한 함수를 사용하면 브라우저 창에 무언가를 표시할 때마다 매번 “document.write”를 입력해야 하는 번거로움을 피할 수 있습니다. 이 함수는 출력하려는 내용이 정의되지 않은 경우(undefined) 이를 알려주지는 않지만, “w();” 명령을 실행하여 빈 줄을 표시할 수는 있습니다.

    function w(m)  {        // 출력 함수.
    m = “” + m + “”;        //  m 변수가 문자열인지 확인합니다.
    if (“undefined” != m)  {        //  빈 문자열이나 기타 정의되지 않은 항목인지 확인합니다.
        document.write(m);
        }
    document.write(“<br>”);
    }

    w(‘<IMG SRC="horse.gif">’);
    w();
    w(“이것은 말의 판화입니다.”);
    w();

writeln( ) 메서드는 write( ) 메서드와 거의 동일하지만, 제공된 문자열 뒤에 줄바꿈 문자를 추가한다는 점이 다릅니다. HTML에서는 일반적으로 항목 뒤에 공백 하나만 추가되지만, <PRE> 및 <XMP> 태그를 사용하는 경우 줄바꿈 문자가 문자 그대로 해석되어 브라우저에 표시됩니다.

     write( ) 메서드를 호출하면, 호출 시점에 문서가 열려 있거나 파싱 중인 상태가 아닐 경우 문서를 열고 내용을 지우게 되므로 위험할 수 있습니다. 이 예제는 1분마다 시간을 표시하도록 설계된 스크립트를 보여주지만, 실행 과정에서 자체적으로 내용을 지워버리기 때문에 첫 번째 실행 이후에는 제대로 작동하지 않습니다.

        <HTML>
        <HEAD>
        <SCRIPT LANGUAGE="JScript">
        function singOut()  {
        var theMoment = new Date();
        var theHour = theMoment.getHours();
        var theMinute = theMoment.getMinutes();
        var theDisplacement = (theMoment.getTimezoneOffset() / 60);
        theHour -= theDisplacement;
        if (theHour > 23)  {
        theHour -= 24
        }
        document.write(theHour + “ 시간, ” + theMinute + “ 분, 협정 세계시.”);
        window.setTimeout(“singOut();”, 60000);
        }
        </SCRIPT>
        </HEAD>
        <BODY>
        <SCRIPT>
        singOut();
        </SCRIPT>
        </BODY>
        </HTML>

    document.write() 대신 window 객체의 alert() 메서드를 사용하면 스크립트가 정상적으로 작동합니다.

        window.alert(theHour + “ 시간, ” + theMinute + “ 분, 협정 세계시(UTC).”);
        window.setTimeout(“singOut();”, 60000);
        }

현재 문서 지우기

문서 객체의 clear() 메서드는 현재 문서의 내용을 모두 지웁니다. 이 메서드는 (문서의 나머지 부분과 함께) 스크립트도 지우므로, 사용 방법과 시점에 각별히 주의해야 합니다.

    document.clear();

  


=== Using Message Boxes


alert, prompt 및 confirm 사용

    alert, confirm 및 prompt 메시지 상자를 사용하여 사용자로부터 입력을 받아옵니다. 이 상자들은 window 객체 인터페이스의 메서드입니다. window 객체는 객체 계층 구조의 최상위에 있으므로, 실제로는 이러한 메시지 상자의 전체 이름(예: “window.alert()”)을 사용할 필요가 없지만, 해당 메서드가 어떤 객체에 속하는지 기억하는 데 도움이 되므로 전체 이름을 사용하는 것이 좋습니다.

알림(Alert) 메시지 상자

    alert 메서드에는 사용자에게 표시할 텍스트 문자열이라는 하나의 인자가 있습니다. 이 문자열은 HTML이 아닙니다. 이 메시지 상자에는 사용자가 닫을 수 있는 ‘확인(OK)’ 버튼이 제공되며, 모달(modal) 방식이므로 사용자는 작업을 계속하기 전에 메시지 상자를 닫아야 합니다.

        window.alert(“환영합니다! 계속하려면 '확인'을 누르세요.”);

확인 메시지 상자

    확인 메시지 상자를 사용하면 사용자에게 “예/아니오” 형식의 질문을 할 수 있으며, 사용자는 ‘확인’ 버튼이나 ‘취소’ 버튼 중 하나를 클릭할 수 있습니다. confirm 메서드는 true 또는 false를 반환합니다. 또한 이 메시지 상자는 모달 방식이므로, 사용자는 다음 단계로 진행하기 전에 반드시 응답(버튼 클릭)을 통해 상자를 닫아야 합니다.

        var truthBeTold = window.confirm(“계속하려면 '확인'을 클릭하세요. 중지하려면 '취소'를 클릭하세요.”);
        if (truthBeTold) {
        window.alert(“저희 웹 페이지에 오신 것을 환영합니다!”);
        }  else  window.alert(“그럼 이만!”);

프롬프트 메시지 상자

    프롬프트 메시지 상자는 사용자가 프롬프트에 대한 응답으로 답변을 입력할 수 있는 텍스트 필드를 제공합니다. 이 상자에는 ‘확인’ 버튼과 ‘취소’ 버튼이 있습니다. 두 번째 문자열 인수를 지정하면, 프롬프트 메시지 상자는 해당 문자열을 텍스트 필드에 기본 응답으로 표시합니다. 그렇지 않으면 기본 텍스트는 “<undefined>”입니다.

    alert( ) 및 confirm( ) 메서드와 마찬가지로, prompt는 모달 메시지 상자를 표시합니다. 사용자는 계속 진행하기 전에 이 상자를 닫아야 합니다.

        var theResponse = window.prompt(“Welcome?”, “Enter your name here.”);
